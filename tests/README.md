# 점검 실행 방법

모든 명령은 저장소 맨 위 폴더에서 친다. 처음 한 번 `npm --prefix tests install`.
브라우저 점검은 이 컴퓨터에 설치된 Chrome을 쓴다(Playwright `channel: 'chrome'`).

| 명령 | 하는 일 | 걸리는 시간(대략) |
|---|---|---|
| `npm --prefix tests run check` | 단위 점검(`tests/unit`)과 점검(`tests/checks`) 전부. 브라우저 점검 포함 | 몇 분 |
| `npm --prefix tests run check:ci` | 브라우저 없는 점검만(GitHub 올릴 때 도는 것) | 1분 안팎 |
| `npm --prefix tests run e2e` | **끝까지 풀기** 전체(아래). 길어서 `check`에는 넣지 않았다 | 5~10분 |

`check`와 `e2e`는 따로 돈다. 배포 전에는 둘 다 돌린다.

## 끝까지 풀기 (`tests/e2e/`)

실제 게임(`index.html`)을 첫 화면부터 화면의 단추를 눌러 끝까지 진행한다(spec §18-1 6·7).

- `play-level.mjs --level m|h1|h23` — 학교급 하나의 추천 묶음을 끝까지 푼다.
  시작 → 처음 정하기(중학교·고2~3은 화면에서 학교급 고르기, 고1은 주소 `?level=h1`로 건너뛰기) → 서장 →
  장면 고르기 → 묶음 장면 전부(고1은 추천 선택 s10 포함) → 장면 고르기.
  - 장면마다 항목을 한 번씩 일부러 틀린다: 해독 항목은 오해 장면이 뜨는지, 기믹 과제는 틀린 부분 표시가 뜨는지 본다.
  - 장면 도중 새로 고침 → 이어 하기(항목 상태 그대로, 주인공은 처음 자리).
  - 수첩 이미지: 장면 도중(진행 중), 장면 끝 저장 제안, 장면 고르기의 수첩(완료) — PNG인지 확인.
  - 묶음 밖 장면에 한 번 들어가 안내를 본다.
  - 교사 모드(중학교·고2~3은 설정 단추, 고1은 주소 `?teacher=1`): 장소 목록으로 걷기 건너뛰기, 정답 바로 보기,
    끈 뒤 학생 기록이 바이트까지 같다.
  - 끝에 장면 고르기에서 묶음 장면이 모두 완료·패 글자, 칭호 '정음 통사'.
- `screens.mjs` — 화면 크기 6종(1920×1080, 1280×800, 1366×768, 390×844, 360×740, 844×390)에서
  첫 화면·처음 정하기·장면 고르기·설정·수첩·장면 창(대사·맥락·항목·오해 장면·과제)에 가로 스크롤이 없고,
  실제 장면 맵에서 움직임 세 가지(키보드·누른 곳으로 걷기·조이스틱)가 된다.
- 둘 다 내내 콘솔 오류·게임 오류(`window.__nmErrors`)·외부 요청이 0이어야 하고, 점검 통로가 화면에 보이면 안 된다.

하나만 돌리기:

```
node tests/e2e/run.mjs --only h1            # 학교급 하나
node tests/e2e/run.mjs --only m,screens
node tests/e2e/play-level.mjs --level h23
node tests/e2e/screens.mjs --only 390x844
```

걷기는 `NM.engine.goTo`(교사 모드 장소 목록과 같은 길)로 건너뛰고, 기믹 과제의 답은 점검 통로
`NM.ui.itemTask.test.submit`으로 낸다(기믹 화면 조작은 `tests/checks/g-*-browser.mjs`가 맡는다).
화면 그림은 `tests/shots/e2e/`에 남는다(git이 무시하는 폴더).
