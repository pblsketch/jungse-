# 나랏말ᄊᆞ미

중·고등학교 국어 시간에 쓰는 **중세국어 해독 어드벤처 웹 게임**입니다.
2026년의 학생이 흩어진 글자를 따라 과거로 떨어지고, 15세기 한양에서 **정음 통사**(새 글자와 사람들의 말을 잇는 통역관 — 게임 설정)로 일합니다.
학생은 옛 문헌의 낱말과 규칙을 하나씩 읽어 내고, 그 뜻으로 사람들 사이의 말을 옮겨 줍니다.

- 대상: 중학교(지학사 중학 국어 2-2), 고1(공통국어2), 고2~3(화법과 언어)
- 장면: 서장, 스테이지 1~11, 종장 — 모두 13개
- 계정·서버 없음. 진행은 학생 기기의 브라우저에만 저장되고 어디로도 보내지 않습니다.
- 점수·랭킹·타이머·게임오버가 없습니다. 틀리거나 도움을 받아도 장면을 끝낼 수 있습니다.

**만든이**: 박준일(온양여자고등학교 국어 교사). 수업에 쓰면서 함께 고쳐 갑니다.

## 1. 학생이 어려워하는 점과 게임 장치

설계를 시작할 때 정리한 표([design/research/03_게임_아이디어.md](design/research/03_게임_아이디어.md) §1)를 실제로 만든 장치에 맞춰 다시 적었습니다.

| 학생이 어려워하는 점 | 왜 어려운가 | 게임 장치 (어디서) |
|---|---|---|
| 옛글자(ㆍ ㅿ ㆆ ㅸ)가 무섭고 읽는 법을 모른다 | 처음 보는 기호라서 | **서장 「흩어진 글자」**: 「세종어제훈민정음」에서 흩어진 글자를 '아는 글자 / 모르는 글자(28자 안·28자 밖)'로 가른다. 다 가르면 **옛글자 도감**이 열린다. 낯선 글자가 '모을 것'이 된다 |
| 원문이 외계어처럼 보여 읽기를 포기한다 | 이어 적기·띄어쓰기 없음·한자음 표기가 한꺼번에 나온다 | **해독 항목**: 같은 말이 쓰인 곳을 맵에서 **두 군데** 찾아 살핀 뒤 뜻 카드 3~4장 가운데 하나를 고른다. 확정하면 화면 곳곳의 같은 말 옆에 현대어 풀이가 붙는다. 스테이지 9에서는 서문 전체를 구절마다 풀어 옮긴다 |
| 제자 원리를 용어로만 외운다 | 원리를 직접 써 본 적이 없다 | **스테이지 2 「소리 → 글자 변신」**: 발음 기관 단면도를 보고 기본 글자의 획 조각을 고르고, 획을 더하고, 천지인(ㆍ ㅡ ㅣ)을 합쳐 모음을 만든다 |
| 모아쓰기·나란히 쓰기(병서)가 헷갈린다 | 글자를 늘 완성형으로만 봤다 | **스테이지 3 「음절 조립」**: 초성·중성·종성 자리에 글자 블록을 모아 물건 이름표를 쓴다 |
| 주격 조사 '이/ㅣ/Ø' 같은 규칙이 추상적이다 | 표로만 배운다 | **규칙 카드 발견**: 사례를 모은 뒤 규칙 문장의 빈칸을 채워 카드를 완성한다. 카드는 해독 수첩에 붙고 뒤 장면에서 다시 쓰인다(스테이지 6 등) |
| 이어 적기·8종성법을 '틀린 맞춤법'으로 오해한다 | 현대 맞춤법을 기준으로 본다 | **스테이지 4 「끊어 읽기」**: 띄어쓰기 없는 원문을 낱말 경계로 끊고, 두 장에서 같은 말을 견준다. **스테이지 11**에서는 이어/거듭/끊어 적기를 가른다 |
| 방점이 무엇인지 감이 안 온다 | 소리의 높낮이를 들어 본 적이 없다 | **방점 음높이 막대**(스테이지 4): 평성 = 낮은 막대, 거성 = 높은 막대, 상성 = 오르는 막대. 정확한 높낮이는 학설이 갈려 '해석' 표지를 달고 채점하지 않는다 |
| 의미 변화 낱말(어리다·어엿브다)을 외우기만 한다 | 맥락 없이 목록으로 배운다 | **오해 장면**: 틀린 뜻으로 통역하면 이야기가 이상해지는 장면과 반응 그림이 나온다(스테이지 5가 중심, 다른 장면에도 있음) |
| 높임 선어말 어미가 누구를 높이는지 헷갈린다 | 주체·객체·상대 높임을 표로만 본다 | **스테이지 7 「높임 저울」**: 높임 받는 사람을 고르고 활자를 끼우면 저울이 기운다 |
| 물음의 종류와 어미가 헷갈린다 | 예문이 적다 | **스테이지 8 「질문 짝 맞추기」**: 물음마다 짝이 되는 대답, 물음의 갈래, 끝맺는 어미를 고른다 |
| 한자를 빌려 쓴 표기(향찰·지명)가 낯설다 | 한자를 뜻으로만 읽는다 | **스테이지 1 「뜻이냐 소리냐」**: 한자마다 뜻을 빌렸는지 소리를 빌렸는지 가른다 |
| 변화의 시기가 뒤섞인다 | 연도만 외운다 | 연도가 아니라 **순서**로 다룬다. **스테이지 10 「두 시대 수첩」**(15세기와 16세기 견주기), **스테이지 11 「세 시대 잇기」**(중세 → 근대 → 현대), **종장 「변화의 강」**(바뀌는 순서 놓기, 연도는 채점 안 함) |
| 왜 배우는지 모른다 | 지금 생활과 끊겨 있다 | **종장**: 고등판은 지금 일어나는 변화 찾기와 500년 뒤 예측 한 줄, 중학교판은 한·중·일 입력 방식, 'ㅏ'와 'a' 음성 인식, 모아쓰기와 풀어쓰기 |
| 창제 정신을 문장으로만 외운다 | 그 시대 사람의 처지를 겪어 보지 않았다 | **스테이지 2**에서 글 모르는 백성에게 새 글자를 만들어 주고, **스테이지 9**에서 서문을 읽으며 구절마다 창제 정신을 찾는다 |

장면이 끝나면 통사 패에 **패 글자**가 새겨지고, 학생은 **돌아보기 한 줄**(채점 안 함)을 쓰고, **수첩 이미지**(PNG 한 장)를 저장할 수 있습니다.
수첩 이미지에는 확정한 낱말과 규칙 카드, 스스로 확정한 말과 도움 받아 확정한 말의 수, 오해 장면 횟수, 완료/진행 중 표시가 들어갑니다(첫 시도 정확도 같은 비율은 넣지 않습니다). 이름·번호는 저장하는 순간에만 적고 기기에 남기지 않습니다. 제출물로 받기 좋습니다.

## 2. 실행하기

### 웹 주소

**https://pblsketch.github.io/naratmalssami/**

- 아직 공개 전입니다. 저장소 이름을 바꾸고 GitHub Pages를 켜면 이 주소로 열립니다.
- 크롬·엣지·사파리 같은 최신 브라우저에서 엽니다. 설치할 것은 없습니다.
- `index.html` 파일을 **더블클릭해서 여는 방식은 쓰지 않습니다**(브라우저가 파일 읽기를 막아 게임이 돌지 않습니다).

### 주소 값 (학교급·교사 모드)

주소 끝에 값을 붙이면 학교급을 정하거나 교사 모드를 켤 수 있습니다. 키 이름은 `js/ui/app-url.js`에 있는 그대로입니다.

| 키 | 값 | 하는 일 |
|---|---|---|
| `level` | `m`(중학교) · `h1`(고1) · `h23`(고2~3) | 이번 접속의 학교급. 기기에 기록이 있으면 **이번 접속에만** 쓰고 기록의 학교급은 바꾸지 않습니다. 기록이 없는 첫 실행이면 학교급 고르기를 건너뛰고 이 값을 처음 학교급으로 저장합니다 |
| `teacher` | `1` | 이번 접속에서 교사 모드를 켭니다. 저장하지 않으므로 이 값 없이 새로 고침하면 꺼집니다 |

- 모르는 값(예: `level=x`, `teacher=0`)은 없는 것으로 봅니다.
- 두 값을 함께 쓸 때는 `&`로 잇습니다.

예시 링크(공개 뒤에 열립니다):

| 쓰임 | 주소 |
|---|---|
| 중학교 학생에게 나눠 줄 링크 | https://pblsketch.github.io/naratmalssami/?level=m |
| 고1 학생에게 나눠 줄 링크 | https://pblsketch.github.io/naratmalssami/?level=h1 |
| 고2~3 학생에게 나눠 줄 링크 | https://pblsketch.github.io/naratmalssami/?level=h23 |
| 전자칠판에서 교사 모드(고1) | https://pblsketch.github.io/naratmalssami/?teacher=1&level=h1 |
| 전자칠판에서 교사 모드(학교급은 켤 때 고르기) | https://pblsketch.github.io/naratmalssami/?teacher=1 |

학생용 링크는 QR 코드로 만들어 칠판에 띄우면 편합니다.

### 내 컴퓨터에서 시험해 보기 (내용을 고친 뒤 확인할 때)

[Node.js](https://nodejs.org/)(18 이상)가 있으면 저장소 폴더에서 아래 한 줄로 작은 웹 서버를 띄웁니다. 서버는 이 컴퓨터 안에서만 열립니다.

```
node tests/server.mjs
```

그리고 브라우저에서 **http://127.0.0.1:8770/** 을 엽니다. 주소 값도 똑같이 붙일 수 있습니다(예: http://127.0.0.1:8770/?teacher=1&level=m). 끌 때는 그 창에서 Ctrl+C를 누릅니다.

## 3. 차시 운영

### 학교급별 추천 묶음

스테이지 고르기 화면에서는 서장을 끝낸 뒤 12개 장면이 **모두 열려 있습니다**. 자기 학교급 추천 묶음에 든 장면에는 표시가 붙고, 묶음 밖 장면에도 들어갈 수 있습니다(처음 들어갈 때 "고등학교에서 배우는 내용이에요" 같은 안내가 한 번 뜹니다).
묶음은 `js/data/stages.js`에 있습니다.

- **서장**(약 8~9분)은 처음에 한 번 합니다. 서장을 끝내야 스테이지 고르기가 열립니다. 칭호 계산에는 들어가지 않습니다.
- 스테이지 9와 종장은 중학교판이 따로 있습니다(학교급에 따라 자동으로 바뀝니다).
- 장면 하나는 10~12분을 목표로 만들었지만, AI 플레이테스트 추정(보통 학생)으로는 **장면마다 약 10~22분**입니다(스테이지 2 중학교판 약 18분, 스테이지 10 약 15~16분, 스테이지 11 약 22분). 장면별 값은 [`design/qa/playtest-2026-10-02.md`](design/qa/playtest-2026-10-02.md)에 있습니다.

### 차시 계획 예시

시간은 위의 AI 플레이테스트 추정(보통 학생)으로 짰습니다. 첫 차시 앞부분 5분은 접속·별명 짓기에, 끝 5~10분은 수첩 이미지 저장과 나누기에 둡니다. 한 차시에는 장면 2~3개가 알맞습니다.

**중학교 (45분, 2차시 권장)**

| 차시 | 할 일 |
|---|---|
| 1차시 | 접속·주인공·별명 정하기 → 서장(약 9분) → 스테이지 2 스물여덟 자(약 18분) → 수첩 이미지 저장 |
| 2차시 | 스테이지 3 모아 써야 소리가 된다(약 12분) → 스테이지 9(중학교판, 약 11분) → 종장(중학교판, 약 11분) → 수첩 이미지 제출, 줄임말 '두 관점 돌아보기' 나누기 |

묶음 전체는 약 60분이라 한 차시에 다 할 수는 없습니다.

**고1 (50분, 2~3차시)**

| 차시 | 할 일 |
|---|---|
| 1차시 | 접속·정하기 → 서장(약 8분) → 스테이지 4 소리대로 적은 책(약 13분) → 스테이지 5 사라진 소리, 바뀐 뜻(약 12분) → 수첩 이미지 저장 |
| 2차시 | 스테이지 6 말을 잇는 끈(약 11분) → 스테이지 9 나랏말ᄊᆞ미(약 14분) → 종장 말의 강(약 12분) → 수첩 이미지 제출 |
| 3차시(선택) | 스테이지 10 백 년 뒤(추천 선택, 약 15분) → 오해 장면·규칙 카드 함께 돌아보기(전자칠판 교사 모드) |

**고2~3 (50분, 5차시)**

| 차시 | 할 일 |
|---|---|
| 1차시 | 접속·정하기 → 서장(약 8분) → 스테이지 1 빌려 쓴 글자(약 10분) → 스테이지 4(약 14분) |
| 2차시 | 스테이지 5(약 12분) → 스테이지 6(약 13분) → 스테이지 7 높이는 말(약 12분) |
| 3차시 | 스테이지 8 묻는 말(약 14분) → 스테이지 9(약 14분) → 오해 장면·규칙 카드 함께 돌아보기 |
| 4차시 | 스테이지 10 백 년 뒤(약 16분) → 스테이지 11 끊어 적는 시대(약 22분 — 해독 항목이 많아 한 차시의 대부분을 씁니다) |
| 5차시 | 종장 말의 강(약 12분) → 수첩 이미지 제출·나누기, 못 끝낸 장면 마저 하기 |

묶음 전체는 약 2시간 25분입니다. 4차시로 줄이려면 스테이지 7·8 가운데 하나를 과제로 돌리는 방법이 있습니다.

### 시범 수업에서 볼 것

처음 한두 반에서 돌려 볼 때 아래를 살펴 두면 다음 차시와 내용 고치기에 도움이 됩니다.

- **대화를 넘기기 시작하는 곳**: 어느 장면, 몇 번째 대사쯤에서 학생들이 `다음`을 읽지 않고 연달아 누르는지 봅니다. 그 대사는 줄이거나 나눌 후보입니다.
- **단서를 실제로 읽는지**: 맥락 창의 원문과 대사를 읽고 카드를 고르는지, 카드를 번갈아 눌러 맞히는지 봅니다. 해독 창의 `살핀 곳` 칩을 펼쳐 다시 보는 학생이 있는지도 봅니다.
- **도움으로 푼 말을 나중에 혼자 푸는지**: 수첩의 `도움 받아 확정한 말`을 메모해 두었다가, 같은 규칙이 다시 나오는 장면(예: 주격 조사는 스테이지 6 → 10 → 11)에서 혼자 확정하는지 봅니다.
- **장면을 끝내는 시간**: 학생마다 장면 하나를 끝내는 데 걸린 시간을 적어 위 차시 계획 예시와 견줍니다. 오래 걸리는 장면은 과제로 돌리거나 차시를 나눕니다.
- **게임 밖 예문으로 확인**: 게임에 나오지 않은 새 예문 2~3개(같은 규칙이 쓰인 중세 국어 문장)를 플레이 직후와 다음 차시에 각각 풀게 합니다. 직후에만 맞히면 게임 속 정답을 기억한 것이고, 다음 차시에도 맞히면 읽는 힘이 생긴 것으로 볼 수 있습니다.

### 운영할 때 알아 둘 것

- **기록은 기기마다 하나**입니다. 같은 학생이 다음 차시에도 **같은 기기, 같은 브라우저**로 들어와야 이어서 할 수 있습니다. 공용 크롬북을 여러 학생이 돌려 쓰면 기록이 섞입니다.
- 시크릿(사생활 보호) 창에서는 창을 닫으면 기록이 사라집니다.
- 첫 화면의 `새로 시작`은 확인을 한 번 받은 뒤 그 기기의 기록을 모두 지웁니다.
- 장면 도중에 나갔다 들어와도 해독한 내용과 수첩은 이어집니다(캐릭터 위치만 시작 자리로 돌아갑니다).
- 별명은 한글·영문·숫자 1~8자입니다. 화면에 실명을 쓰지 말라는 안내가 나옵니다.
- 소리는 화면을 처음 누르거나 키를 누른 뒤에 납니다. 교실에서는 설정에서 배경음을 끄게 해도 됩니다.
- 조작: 화면의 조이스틱, 가고 싶은 곳 누르기, 키보드(방향키·WASD로 이동, E·Enter로 살피기) 모두 됩니다.
- 지도를 보기 어려운 학생은 장면 도구줄의 `장소 목록`에서 갈 곳을 고를 수 있습니다. 목록에 이름·종류·목표 여부·살펴봤는지가 나오고, 고르면 그곳까지 걸어간 뒤 '○○ 살피기' 단추로 초점이 옮겨 갑니다(키보드·화면 낭독기로 끝까지 진행 가능). 살피기 단추와 목표 표시(!·화면 가장자리 화살표)에도 대상 이름이 붙습니다.

## 4. 교사 모드 쓰는 법

전자칠판에서 함께 풀거나, 수업 전에 장면을 빠르게 훑어볼 때 씁니다.

### 켜는 법 (잠금 없음)

- **주소로 켜기**: 주소 끝에 `?teacher=1`을 붙입니다(예: https://pblsketch.github.io/naratmalssami/?teacher=1&level=h23). 학교급 값도 함께 붙이면 그 학교급으로 시작합니다.
- **설정에서 켜기**: 첫 화면이나 스테이지 고르기 화면의 `설정` → `교사 모드 켜기`. 주소에 학교급이 없으면 이때 학교급을 고릅니다. 장면 안에서는 교사 모드와 학교급을 켜고 끌 수 없습니다(장면을 나와서 바꿉니다).
- 비밀번호는 없습니다. 학생이 켜도 막지 않습니다. 대신 교사 모드에서는 기록이 남지 않고, 그때 만든 수첩 이미지에는 `교사 모드` 표시가 찍힙니다.

### 켜져 있는 동안

| 기능 | 하는 일 |
|---|---|
| 걷기 건너뛰기 | 장면 도구줄의 `장소 목록` 단추를 누르면 조사 지점·인물 목록이 나옵니다. 고르면 걷지 않고 바로 그 자리로 가서 살펴봅니다 |
| 크게 보기 | 원문(옛한글·방점 포함), 풀이, 대사, 단추가 모두 크게 보입니다(따로 켤 필요 없음) |
| 정답 바로 보기 | 항목마다 `정답과 풀이 바로 보기` 단추가 생깁니다 |
| 서장 건너뛰기 | 서장을 하지 않고도 스테이지 고르기로 갈 수 있습니다 |
| 기록 손대지 않음 | 그 기기의 학생 기록을 **읽지도 바꾸지도 않습니다**. 교사 진행은 메모리에만 있어서 새로 고침하면 처음부터입니다 |

- 교사 모드는 기본 설정, 주인공 1번, 호칭 '통사'(별명 없음)로 진행합니다.
- 교사 모드에서는 `새로 시작`(기록 지우기)을 쓸 수 없습니다.
- 교사 모드를 끄면 그 기기의 학생 기록이 그대로 다시 보입니다. 그래서 학생 기기를 잠깐 빌려 시연해도 학생 기록이 망가지지 않습니다.
- 주소 값으로 켰다면 새로 고침해도 다시 켜집니다. 설정에서 켰다면 새로 고침하면 꺼집니다.

## 5. 실제와 상상

게임 안에서 지어낸 것에는 `게임 설정 · 虛` 표지가 한 줄로 붙고, 옆의 `실제 역사 보기`를 누르면 "실제로는 →" 설명이 펼쳐집니다(장면을 처음 시작할 때 이야기 앞에 그 장면의 표지가 모여 나옵니다). 아래 표는 장면 데이터(`js/data/scenes/<id>.js`의 `fiction`)에 적힌 내용을 모은 것입니다.

### 지어낸 것 (게임 설정 · 虛)

| 장면 | 지어낸 것 | 실제로는 (게임에 나오는 설명) |
|---|---|---|
| 모든 장면 | **정음 통사**: 새 글자(정음)와 사람들의 말 사이를 이어 주는 통역관 | 이런 직책은 없었어요. 조선의 통사는 외국어 통역관이었고, 정음 통사는 이 이야기에서 지어낸 일이에요 |
| 서장·전체 | 2026년 학생이 흩어진 글자를 따라 과거로 떨어지고, 장면 사이를 시간 건너 오간다 | 시간을 건너는 길은 이야기 설정입니다. 주인공 4명과 선배 통사도 지어낸 인물입니다 |
| 스테이지 1 | 마을 비석과 서기의 목간에 고을의 옛 이름과 새 이름이 적혀 있다 | 이 이름들은 비석이나 목간이 아니라, 고려 때(1145) 엮은 역사책 『삼국사기』의 지리지에 실려 전해요 |
| 스테이지 1 | 한 마을에서 아이는 「서동요」를, 여인은 「처용가」를 부른다 | 두 노래는 고려 때(1281년 무렵) 엮은 『삼국유사』에 향찰로 적혀 전해요. 생겨난 때와 곳이 서로 달라서, 한 마을에서 함께 불렸다는 근거는 없어요 |
| 스테이지 2 | 궁 안뜰에 백성들이 모여 새 글자가 생겨난 길을 구경하는 장면 | 이런 일이 있었다는 기록은 없어요. 이야기를 위해 지어낸 장면이에요 |
| 스테이지 2 | 세종이 통사와 백성에게 건네는 말 가운데 서문에 없는 말 | 그 대사는 지어낸 것이에요. 세종이 새 글자를 만든 뜻은 훈민정음 서문으로 전해져요 |
| 스테이지 3 | 저잣거리 담벼락에 새 글자 쓰는 법을 적은 방 | 이런 방이 붙었다는 기록은 없어요. 해례 합자해에 적힌 내용을 방으로 옮겨 보인 설정이에요 |
| 스테이지 4 | 1447년의 활자 인쇄소와 장인, 문 앞에서 책을 기다리는 백성들 | 이야기를 위해 지어낸 무대예요. 「용비어천가」를 어디서, 누가, 어떤 방법으로 찍었는지는 이 장면에서 다루지 않아요 |
| 스테이지 5 | 장터에 새 글자로 쓴 방과 쪽지가 나붙은 장면 | 장터에 이런 방이나 쪽지가 붙었다는 기록을 바탕으로 한 장면이 아니에요. 방에 보이는 서문의 우리말 풀이는 1459년 『월인석보』 첫머리에 실려 전해요 |
| 스테이지 5 | 나루에 떠밀려 온 뒷날의 책장 | 이 두 구절은 1481년에 펴낸 『분류두공부시언해』에 실려 있어요. 1450년대 장터에는 아직 없던 책이에요 |
| 스테이지 6 | 관아가 백성의 진술을 새 글자로 받아 적는 일 | 이 무렵 관아의 공식 문서는 한문으로 적었어요. 진술을 새 글자로 받아 적는 장면은 이야기를 위해 만든 설정이에요 |
| 스테이지 7 | 높임 저울의 인물 패 이름('노래를 지은 이', '노래를 듣는 이' 등) | 구절마다 말하는 이와 듣는 이가 정확히 누구인지는 따로 확인하지 않았어요. 인물 이름은 이해를 돕는 설정이고, 판정은 높이는 자리(주체, 객체, 상대)만 봐요 |
| 스테이지 9 | 흩어진 서문을 처음부터 끝까지 읽어 내면 돌아갈 길이 열린다 | 이야기를 위해 지어낸 설정이다. 실제 서문은 『월인석보』 권1 첫머리에 실려 전한다 |
| 스테이지 9 | 서문이 다 모이자 빛 속에 떠오른 세종(회상 모습) | 세종은 1450년에 세상을 떠났다. 『월인석보』가 나온 1459년에는 살아 있지 않았으니, 이 장면의 세종은 이야기를 위해 그린 회상 모습이다. 세종의 말은 서문의 뜻을 옮긴 것이다 |
| 스테이지 10 | 서문을 다 읽고 돌아가려던 길이 백 년 뒤 서당에 닿았다 | 시간을 건너는 길은 이야기 설정이에요. 『소학언해』는 1587년에 언해를 마치고 1588년에 펴낸 실제 책이에요 |
| 스테이지 11 | 한 길을 걸으며 18세기에서 개화기까지 지나간다 | 백 년 넘는 시간을 한 길에 이어 놓은 것은 이야기 설정이에요. 길에서 만나는 글은 모두 실제 책과 신문이에요 |
| 스테이지 11 | 의유당이 길에서 통사와 이야기를 나눈다 | 의유당은 관북 지방을 다니며 본 것을 한글 기행문으로 남긴 실제 인물이에요. 이 장면에서 그가 하는 말은 지어낸 것이에요 |
| 종장 | 말의 강: 옛말이 물길을 따라 지금 말까지 흘러오는 곳 | 이야기를 위해 지어낸 장소다. 실제로 말은 사람들이 쓰는 동안 오랜 세월에 걸쳐 조금씩 바뀐다 |

- 세종은 스테이지 2와 9에 나옵니다. 대사는 서문과 기록에 근거한 말로 쓰고, 지어낸 대사에는 `게임 설정 · 虛` 표지를 답니다.
- 장면에 나오는 사람들(백성, 관원, 장인, 서당 아이 등)과 그들의 대사는 모두 지어낸 것입니다. 대사와 풀이는 교과서·번역서·시험 지문을 옮기지 않고 새로 썼습니다.

- 판본마다 다른 글자는 `이본 노트`로 보여 주고 채점하지 않습니다.
- 학설이 갈리는 것(ㆍ의 정확한 소리값, 변화의 정확한 연도, 방점의 정확한 높낮이 등)은 `해석` 표지를 달고 채점하지 않습니다.
- 사실 카드(`알아 두기`)에는 출처를 답니다. 교과서에 없는 내용은 채점하지 않고 알아 두기로만 둡니다.
- 확실도가 낮은(△) 원문은 게임 데이터에 넣지 않았습니다(예: 「동명일기」 대목, 1907년 『만세보』 광고). 그래서 스테이지 11의 의유당은 原文 없이 말로만 나옵니다.

### 옛한글 적는 법

데이터에는 사람이 읽고 고칠 수 있는 표기를 쓰고, 게임이 화면에 띄울 때 옛한글로 조합합니다. 자세한 규칙은 [js/data/scenes/README.md](js/data/scenes/README.md)와 [방점 표기 결정 기록](design/decisions/0001-방점-표기.md)에 있습니다.

| 적는 법 | 뜻 | 예 |
|---|---|---|
| `[ㅁㆍㄹ]` | 대괄호 = 옛한글 한 음절(낱자를 차례로 늘어놓음) | `[ㅁㆍㄹ]` → ᄆᆞᆯ |
| `·가` | 음절 **바로 앞**의 가운뎃점 = 거성(점 하나) | `·나랏` |
| `:가` | 음절 바로 앞의 쌍점 = 상성(점 둘) | `:말` |
| `{漢\|한}` | 한자 위에 읽기를 다는 표기 | `{百\|·[ㅂㆎㄱ]}` |
| `<@>`, `<@이>`, `<@아>` … | 학생 별명 자리(받침에 맞춰 조사가 바뀜) | `<@아>, 이리 와 봐.` |

- 가운뎃점을 음절에 **붙여** 쓰면 방점이 됩니다. 그냥 늘어놓을 때는 띄어 씁니다(`가 · 나`).
- 방점은 화면에서 음절 오른쪽의 작은 점으로 보입니다(글꼴의 한계, 원본처럼 왼쪽에 찍히지는 않음).

### 原文은 장면 파일에서 고치지 않습니다

- 장면 파일은 原文을 `O-s4-YB2a` 같은 **블록 id로만** 가리킵니다. 原文 글자는 장면 파일에 없습니다.
- 原文 글자는 리서치 문서(`design/research/09_원문_훈민정음.md`, `design/research/10_원문_15세기문헌.md`, `design/research/11_원문_고대_근대.md`)의 블록에 있고, 도구가 그것을 읽어 `js/data/orig.generated.js`를 만듭니다.
- 교과서와 대조해서 고칠 곳을 찾았다면 리서치 문서의 블록을 고친 뒤 아래 명령으로 다시 만듭니다.

```
node tools/extract_orig.mjs
```

### 새 글자를 넣었다면 글꼴을 다시 만듭니다

게임 글꼴은 데이터에 쓰인 글자만 담은 **부분 글꼴**입니다. 데이터에 새 한자나 새 옛한글 음절을 넣으면 그 글자가 화면에서 빈 네모로 보일 수 있습니다. 점검(`font-coverage`)이 알려 주면 아래처럼 글꼴을 다시 만듭니다(Python 3 필요, 처음 한 번 `python -m pip install fonttools brotli`).

```
python tools/build_fonts.py
```

### 고친 뒤 확인

1. `node tests/server.mjs`로 띄워 그 장면을 해 봅니다(교사 모드로 열면 빠릅니다).
2. 점검을 돌립니다: `npm --prefix tests run check:ci` (아래 8장). 장면 글을 고치는 중에는 글꼴 점검을 뺀 `npm --prefix tests run check:scene`이 빠릅니다.

### Tiled로 맵 고치기

맵은 무료 맵 편집기 **Tiled**(https://www.mapeditor.org/)로 고칩니다.

1. Tiled를 설치하고 `파일 → 열기`로 `maps/<id>.json`(예: `maps/s6.json`)을 엽니다. 배경 그림은 `assets/bg/` 폴더에서 자동으로 불러옵니다.
2. 오른쪽 '레이어' 칸에서 고칠 층을 고르고, 객체를 옮기거나 새로 그립니다.
3. 객체를 고르면 '속성' 칸에서 이름과 사용자 속성(아래 표)을 고칠 수 있습니다. 새 속성은 `+` 단추로 넣고 종류는 '문자열(string)'로 합니다.
4. `파일 → 저장`(JSON 그대로 저장됩니다). 그다음 점검을 돌립니다.

| 층 이름 | 무엇 | 속성 |
|---|---|---|
| `bg` | 배경 그림 한 장(그림 층) | 그림 파일 `assets/bg/<id>.webp`(맵 파일 안에는 맵 폴더에서 본 상대 경로로 적혀 있음). 맵 크기와 그림 크기가 같아야 합니다 |
| `collision` | 못 가는 곳(사각형·다각형) | 없음 |
| `spots` | 조사 지점 | `contextId`(필수, 장면 파일의 맥락 id. 예: `s6.c1`), `act`(선택, 단추 문구 키), `label`(선택) |
| `npcs` | 인물 자리 | `npcId`(필수, 장면 파일 `npcs`의 키), `contextId`(그 인물의 말이 맥락이면), `sprite`(걷는 그림 키. 예: `official`, `child`) |
| `spawn` | 시작 자리 | 점 하나 |

- 해독 항목마다 그 장면 맵 안에 **서로 다른 맥락 2곳 이상**이 있어야 합니다. 조사 지점이나 인물을 지우면 점검이 알려 줍니다.
- 갇힌 빈 곳(어디서도 걸어 들어갈 수 없는 곳)이 생기면 점검이 실패합니다. 일부러 못 가게 할 곳은 `collision`으로 막습니다.
- 맵을 키우거나 줄이면 배경 그림 크기와 모든 좌표를 함께 바꿔야 합니다.

## 8. 점검 실행법

게임 데이터와 화면이 약속대로 되어 있는지 확인하는 자동 점검이 있습니다. 내용을 고친 뒤 돌리면 실수를 찾아 줍니다. 저장소 폴더에서 실행합니다.

**처음 한 번** (점검에 쓰는 도구를 `tests/` 안에 내려받습니다):

```
npm --prefix tests ci
```

| 명령 | 하는 일 |
|---|---|
| `npm --prefix tests run check` | 전부. 브라우저 점검 포함 — 이 컴퓨터에 **크롬**이 깔려 있어야 합니다 |
| `npm --prefix tests run check:ci` | 브라우저 없이 도는 점검만. GitHub에 올릴 때 자동으로 도는 것과 같습니다 |
| `npm --prefix tests run check:scene` | 장면 글을 고치는 중에 빠르게(브라우저·글꼴 점검 뺌) |
| `npm --prefix tests run e2e` | 학교급마다 게임을 처음부터 끝까지 풀어 보는 점검 |

- 마지막 줄 'passed' 앞의 두 숫자가 같으면(예: 40/40) 통과입니다. `FAIL`이 있으면 그 위에 무엇이 틀렸는지 한국어로 나옵니다.
- 그림 도구 점검(`tests/checks/a1-sprite-pipeline.mjs`)은 Python 3과 numpy·Pillow가 필요합니다(`python -m pip install numpy Pillow`).
- 原文 파일이 리서치 문서와 같은지만 볼 때: `node tools/extract_orig.mjs --check`

## 9. 알려진 한계

### 사람이 확인해야 할 것

- **실기기 확인이 아직 남았습니다.** 휴대폰, 크롬북, 전자칠판에서 옛한글과 방점이 바르게 보이는지, 맵이 부드럽게 움직이는지 직접 보아야 합니다. 자동 점검은 이 컴퓨터의 크롬에서만 돌았습니다.
- **장면 시간**은 설계 목표(10~12분)와 AI 플레이테스트 어림값(10~22분)뿐입니다. 실제 학생으로 재야 합니다.
- **AI 플레이테스트는 원문 대조가 아닙니다.** AI가 게임을 끝까지 풀어 본 것은 '막히지 않는가'를 본 것이지, 原文이 교과서와 같은지를 확인한 것이 아닙니다. 아래 ★ 목록은 선생님이 교과서·영인본과 한 번 대조해 주셔야 합니다.
- **글꼴 크기**: 글꼴 파일이 모두 약 3MB입니다. 처음 열 때 학교 와이파이에서 조금 걸릴 수 있습니다.
- **배경음 되풀이 이음매**는 도구로 이었을 뿐 귀로 들어 확인하지 않았습니다. 곡이 끝에서 처음으로 넘어갈 때 튀는 곳이 있는지 들어 봐 주세요.
- **그림**: AI가 그린 그림이라 사람이 다시 볼 곳이 남아 있습니다(선배 통사 철릭 길이, 패랭이 꼭대기, 장면 그림에 주인공 뒷머리가 보이는 것, 세종 복식, 갓 챙 너비 등). 목록은 [design/art/A2_review.md](design/art/A2_review.md)(인물), [design/art/A3_review.md](design/art/A3_review.md)(맵), [design/art/A4_review.md](design/art/A4_review.md)(장면 그림)의 '사람이 다시 볼 것'에 있습니다.
