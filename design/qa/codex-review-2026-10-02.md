## 3. 좋은 점 — 유지할 것

1. **정음 통사라는 역할과 해독 활동의 일치.** 원문을 배우는 이유가 사람의 문제와 연결된다. 지어낸 직책·장면에는 虛 표지가 있다.
2. **점수 경쟁·게임오버 없이 고칠 수 있는 오답.** 오해 장면이 오개념을 구체화하고, 도움으로도 모든 장면을 끝낼 수 있다.
3. **제자 원리·음절 조립의 조작감.** s3의 홰는 ㅗ·ㅏ·ㅣ를 실제로 합쳐야 해서 문항의 정답 이름만 외우는 활동을 넘어선다.
4. **원문·새 풀이·이본·해석을 구별하는 표지.** 특히 창제 정신의 제6구절, 일부 방점·판본 차이를 채점에서 제외한 판단은 유지할 가치가 있다.
5. **학교급별 핵심 범위와 선행 규칙 안내.** 중학교 s9·s12의 별도판, 고1 s10 선택, 고급 높임·의문·근대 자료 구성이 교사 운영에 도움이 된다.
6. **수첩·저장·교사 모드.** PNG는 실제 저장되고 한글과 규칙이 읽힌다. 학생 기록과 교사 시연 기록이 분리되며, 진행 중 재접속도 확인됐다.
7. **일관된 시각 요소.** 한지·붉은 낙관·상태 기호·인물 표정이 같은 세계를 만든다. 색만으로 정오를 표현하지 않는다.

## 6. 이 평가의 한계

- **AI 평가이며 원전 전체 대조·학계 감수·학습효과 검증이 아니다.** 저장소의 README·spec·리서치 01~12·이전 평가와 지정 데이터 파일을 읽고, 쟁점에 한해 외부 학술·공식 자료를 확인했다. 기존 리서치의 대조 성공률을 이번 검증 결과로 재사용하지 않았다.
- 휴대폰은 데스크톱 Chrome의 터치 에뮬레이션이다. Android/iOS 실물, Safari, 학교 크롬북, 전자칠판, 가상 키보드가 뜬 상태, 실제 화면 낭독기, 청각적 음량·음질은 검증하지 않았다.
- P도 자동화된 실제 입력이다. 답을 모르는 학생의 시행착오·정서·읽기 속도를 재현하지 못한다. 렌더 좌표를 읽어 찾아간 경로이므로 지도에서 표식을 스스로 해석하는 능력도 평가되지 않는다.
- A는 기믹 답을 주입했다. s1·s2·s4·s7~s11 등의 모든 기믹 단계를 터치·드래그로 완수했다는 주장은 하지 않는다. 실제 기믹 완주는 s0 분류와 s3 음절 조립에서 확인했다.
- 터미널의 초기 한글 전달 오류와 임시 탐색 스크립트의 목적지 식별 오류가 있었으며 게임 오류 집계에서 제외했다. 실패를 DOM 강제 클릭으로 숨기지 않았다.
- 수첩에 적은 돌아보기는 검증용 동일 문장이다. 본문 예시는 학생의 실제 응답이 아니다. 최초 완료 후 일부 장면을 다시 시작한 것은 확대·재진입 검증을 위한 별도 행동이다.
- Git 상태 명령도 사용하지 않았으므로 기존 미커밋 변경의 목록은 조사하지 않았다. 작업 전후 **3,203개 파일 해시**를 비교했다. 게임 코드·데이터·기존 문서와 `tests/node_modules`의 **183개 파일은 동일**했다. 단, `.gitignore`에 등록된 `.omc/` 안의 `idle-notif-cooldown.json`, 현재 도구 세션의 `pre-tool-advisory-throttle.json` **두 상태 파일의 갱신은 관측됐다**. 평가 스크립트가 편집한 파일은 아니며 도구 자동 상태 갱신으로 보인다. 이 파일들을 되돌리지는 않았다. 따라서 ‘허용 경로 밖 모든 바이트가 동일하다’고 주장하지 않는다. 전체 차이는 [무결성 기록](../../tests/shots/codex/integrity.json)에 남겼다.
