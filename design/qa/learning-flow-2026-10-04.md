# 단계별 만남과 짧은 연습 개선 검증

2026-10-04. 학생 관점 검토에서 확인한 탐색 순서·과제 분량·오답 도움 문제를 수정했다.

## 변경 동작

- 13개 장면에 학습 단계를 정의했다. 지금 단계의 만남·조사부터 표시하고, 조사를 마친 뒤 관련 규칙과 과제를 연다. 같은 단계의 독립적인 비교는 자유롭게 할 수 있다.
- 지도 누르기, 가까운 대상 살피기, 장소 목록, 과제 목록, 직접 열기에서 같은 해제 조건을 적용한다. 잠긴 대상을 누르면 현재 해야 할 일을 안내한다.
- 이미 살핀 단서는 다시 볼 수 있고, 도움으로 완료해도 다음 단계로 진행한다. 교사 모드는 모든 대상을 자유롭게 연다.
- 기존 저장 버전과 항목 ID를 유지했다. 새 기록은 조사 완료를 `visitedContexts`로 저장하고, 예전 기록은 항목별 단서 기록을 활용한다. 이미 완료한 항목은 다시 잠그지 않는다.
- 향찰 분류는 핵심 6글자를 두 글자씩 나누었다. 한자음·새김·구절의 읽기를 함께 제시하고, 예외는 선행 대화와 분류 화면에서 설명하며 기본 분류의 채점에서는 제외한다. 규칙 문장에서는 예외를 고려해 ‘대체로’를 선택한다.
- 자음·모음 만들기는 한 글자씩, 질문 짝 맞추기는 한 물음씩 확인한다. 앞의 선택은 유지하고 이전 사례를 다시 볼 수 있다. 연습 중 오답은 최종 제출의 오답 횟수에 넣지 않는다.
- 오답 뒤의 두 번째 도움은 마지막 제출의 실제 오답을 강조하고 해당 위치로 화면을 이동한다. 자음 과제의 힌트 문장도 상형·가획 등 틀린 부분에 맞춘다.
- 두 시대 수첩에는 지켜짐·흔들림·없음의 판단 기준과 근거 수집 방법을, 종장에는 변화 순서를 판단할 단서를 추가했다.

## 검토 정정과 테스트 수정

처음에는 향찰 예외 설명의 `hidden` 속성만 보고 과제 종료 뒤에만 보인다고 판단했다. 이전 커밋의 JS·CSS를 브라우저에 다시 불러 확인하니 `display: flex`가 숨김 속성을 덮어, 예외 설명이 먼저 렌더링되고 있었다. 기존 검토 문서에 이를 정정했다. 새 페이지 구성에는 명시적인 숨김 규칙을 적용했고, 예외 설명의 제시 시점은 데이터와 대화에서 의도적으로 정했다.

기존 힌트 테스트는 오답과 무관한 고정 대상 강조를 기대했다. 실제 오답 강조와 정답 미노출을 확인하도록 수정했다. 가로 화면의 이동 테스트는 잠긴 조사 지점을 바닥으로 골라 차단 안내를 받았으므로, 실제 이동 검사는 조사 대상 영역을 제외한 바닥을 선택하게 했다. 잠긴 대상의 차단과 안내는 별도 브라우저 검사로 확인한다.

배포와 공개 주소의 실행 확인은 이 로컬 검증과 별도로 수행한다.
