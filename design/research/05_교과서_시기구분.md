## 1. 두 교과서의 시기 구분

### 공통국어2 (130쪽, 소단원 도입 그림의 연표)

| 시기 | 범위 | 경계가 되는 사건 |
|---|---|---|
| 고대 국어 | ~고려 건국 이전 | ← 고려 건국 |
| 전기 중세 국어 | 10~14세기 | ← 훈민정음 창제 |
| **후기 중세 국어** | **15~16세기** | ← 임진왜란 |
| 근대 국어 | 17~19세기 말 | ← 갑오개혁 |
| 현대 국어 | 20세기~ | |

- 본문: "훈민정음이 창제된 시기인, **후기 중세 국어 자료**를 바탕으로 중세 국어와 현대 국어의 차이를 살펴" (130쪽)
- 지도 방안: "학생들이 학습 부담을 크게 느끼지 않는 범위 내에서 **한글 창제 후의 중세 국어 자료**와 현대 국어 자료를 비교" (130쪽)

### 화법과 언어 (202쪽)

**본문 (학생이 배우는 구분)**: 4분법이다.

| 시기 | 범위 |
|---|---|
| 고대 국어 | 통일 신라 시대까지 |
| 중세 국어 | 고려 건국부터 16세기 말까지 |
| 근대 국어 | 17세기 초부터 19세기 말까지 |
| 현대 국어 | 20세기 이후 |

**지도서 '라이브 수업' 난 (교사 참고용)**에는 두 가지 견해가 더 실려 있다.
1. 중세 국어를 **전기**(고려 건국~훈민정음 창제 이전)와 **후기**(훈민정음 창제 이후~임진왜란 이전)로 나누기도 한다.
2. 왕조나 전쟁 같은 **언어 밖의 기준 대신 언어 안의 기준**으로 나누는 견해도 있다: 고대(10세기 이전) · 전기 중세(10~13세기) · **후기 중세(14~16세기)** · 근대(17~19세기) · 현대(20세기 이후).

### 정리

| 구분 | 공통국어2 | 화법과 언어 본문 | 화법과 언어 지도서 참고 |
|---|---|---|---|
| 중세를 둘로 나누는가 | 나눈다 (전기·후기) | 나누지 않는다 | 나누기도 한다 |
| 후기 중세의 시작 | 15세기 (훈민정음 창제) | — | 창제 이후 / 언어 내적 기준으로는 14세기 |
| 중세의 끝 | 16세기 (임진왜란) | 16세기 말 | 임진왜란 이전 |
| 근대 | 17~19세기 말 | 17세기 초~19세기 말 | 17~19세기 |

**두 교과서가 같은 점**: 중세는 16세기 말에 끝나고, 근대는 17~19세기, 현대는 20세기부터다.
**다른 점**: 공통국어2는 학생에게 바로 '전기/후기 중세'를 보여 준다. 화법과 언어는 본문에서 '중세 국어' 하나로 묶는다.

## 2. 학생이 실제로 배우는 범위

### 공통국어2: 후기 중세(15세기)만 다룬다

| 다루는 자료 | 시기 |
|---|---|
| 「세종어제훈민정음」 (『월인석보』 권1) | 1459 |
| 『용비어천가』 제34장 | 1447 |
| 『사흘』 어원 읽기 자료 (사ᄋᆞᆯ → 사흘) | 15세기 → 16세기 |

- **근대 국어는 연표에만 나온다.** 학생 활동은 없다. 지도서 보충 설명에서만 근대를 언급한다(이어적기 → 거듭적기 → 끊어적기, 어두 자음군이 된소리로 바뀐 시기 등).
- 학습 활동 1~4에서 다루는 중세 국어의 특징:
  - 음운: 방점(성조), ㆍ·ㆁ·ㆆ·ㅸ, 어두 자음군, 구개음화 없음, 두음 법칙 없음, 원순 모음화 없음
  - 표기: 이어적기, 띄어쓰기 없음, 8종성법(예외: 깊고·높고)
  - 문법: 주격 조사 이/ㅣ/Ø ('가' 없음), 관형격 ㅅ, 비교의 '에', 명사형 어미 -옴/-움, ㅎ 종성 체언, 주체 높임 -시-, 상대 높임 -ᅌᅵ-
  - 어휘: 말ᄊᆞᆷ·어리다·놈·하다·어엿브다의 의미 변화
- **의문 체계는 공통국어2에 없다.** 높임법은 용비어천가 분석 속에 -시-, -ᅌᅵ-가 나올 뿐 따로 다루지 않는다.

### 화법과 언어: 고대·중세·근대를 모두 다룬다

| 시기 | 본문·활동 자료 | 다루는 내용 |
|---|---|---|
| 고대 | 『삼국사기』 권34 지명(永同郡/吉同郡), 『삼국유사』 서동요 향찰 | 차자 표기(고유 명사 표기·이두·구결·향찰), 훈차·음차 |
| 중세 (15세기) | 『용비어천가』 제2장, 『석보상절』 권6, 『월인석보』 권1 | ㆍ·ㅸ·ㅿ, 어두 자음군, 방점, 모음 조화, 8종성, 이어 적기 / 주격 이·ㅣ·Ø, 관형격 ᄋᆡ·의·ㅅ, **주체·객체·상대 높임**, **의문문(판정 -가, 설명 -고, 2인칭 -ㄴ다)** / 고유어와 한자어의 경쟁, 몽골어 차용 |
| 중세 (16세기 후반) | 『소학언해』 권2 | "16세기 후반 **후기 중세 국어**의 모습". 주격 조사는 아직 'ㅣ'. 끊어 적기와 모음 조화 파괴가 **가끔** 보인다 |
| 근대 | 『의유당관북유람일기』(1772), 『중간노걸대언해』(1795), 『독립신문』 창간사(1896), 『제국신문』 광고(1902), 『만세보』 광고(1907) | ㅸ·ㅿ 소멸, ㆍ 점차 소실, 모음 조화 파괴, 구개음화·원순 모음화, 7종성, 끊어 적기 확대와 거듭 적기, **주격 조사 '가' 출현**, 명사형 어미 '-기' 확대, 외래 어휘 유입 |

- 화법과 언어 본문에서는 '후기 중세'라는 말을 쓰지 않는다. 그런데 『소학언해』 설명(209쪽)에는 '후기 중세 국어'라는 말이 나온다.
- 근대의 끝은 '19세기 말'이라고 해 놓고, 활동 06에서는 1902·1907년 광고를 '근대 국어생활' 자료로 쓴다(개화기). 게임에서 개화기를 어디에 넣을지 정할 때 참고한다.

## 3. 게임 설계에 주는 영향

### 3-1. 04 문서에서 고쳐야 할 것

| 04 문서의 내용 | 교과서 | 조치 |
|---|---|---|
| 후기 중세 = **조선 건국(14세기 말)** ~ 16세기 말 | 후기 중세는 **훈민정음 창제(15세기)** 부터. 언어 내적 기준으로 나누면 14세기부터 | 04 §3-1 표를 교과서 기준으로 고침 |
| 전기 중세 = 고려(10세기~14세기 말) | 공통국어2: 10~14세기 / 화법과 언어 지도서: 고려 건국~창제 이전 | 그대로 둠 (범위가 맞음) |
| 스테이지 9의 16세기 변화 중 **"새 주격 조사의 등장"** | 주격 '가'는 **근대 국어** 특징(화법과 언어 206쪽). 16세기 『소학언해』는 아직 'ㅣ'(209쪽) | 스테이지 9에서 빼고, 종장(근대)으로 옮김 |
| 스테이지 9: ㆁ 소실 | 공통국어2: ㆁ은 ㅇ과 **혼용**되다가 「한글 맞춤법 통일안」 이후 ㅇ으로 통합(135쪽). 16세기에 사라진 것이 아님 | 스테이지 9에서 빼거나 "ㅇ과 섞여 쓰이기 시작"으로 표현을 바꿈 |

### 3-2. 교과서로 확인된 16세기 변화 (스테이지 9 근거)

| 변화 | 근거 |
|---|---|
| 방점: 16세기 중엽부터 흔들리고 16세기 말엽 문헌부터 표시하지 않음 | 공통국어2 지도서 134쪽 |
| ㆍ: 둘째 음절에서 ㅡ로 (사ᄋᆞᆯ → 사흘, 16세기부터) | 공통국어2 138쪽 |
| ㅿ: 중세 말~근대 초에 흔적 없이 소멸 | 화법과 언어 210쪽 |
| 끊어 적기가 가끔 나타남, 모음 조화가 가끔 깨짐 (『소학언해』) | 화법과 언어 209쪽 |

### 3-3. 학년별 경로를 다시 볼 곳

- **고1 경로 (공통국어2)**: 15세기만 다룬다. 의문 체계(스테이지 7)는 교과서에 없고, 높임법(6)도 따로 다루지 않는다. → 04 §6 Q3("의문 체계·높임법을 고1에 넣을까")는 **고1 기본 경로에서 빼는 쪽**에 근거가 생겼다. 스테이지 9(16세기)도 고1에는 선택 사항이 된다.
- **고2~3 경로 (화법과 언어)**: 의문문과 주체·객체·상대 높임이 본문에 있으므로 스테이지 6·7은 이 경로에 맞다. 대신 화법과 언어는 **고대(차자 표기)와 근대**도 본문에서 다루는데, 지금 구성에서는 고대는 서장의 짧은 장면, 근대는 종장에서 지나가기만 한다. → 근대 국어를 스테이지로 키울지 정해야 한다.
- 교과서의 원문은 04 문서의 무대 문헌과 거의 겹친다(세종어제훈민정음, 용비어천가, 석보상절, 월인석보). 새로 생긴 후보 원문: 『소학언해』(16세기), 『중간노걸대언해』·『의유당관북유람일기』·『독립신문』(근대).
