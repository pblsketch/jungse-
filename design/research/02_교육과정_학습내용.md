### 1-4. 교육과정이 게임 설계에 주는 지시 (가장 중요)

교육과정 문구를 그대로 설계 원칙으로 옮기면 다음과 같다.

| 교육과정 문구 | 게임 설계 원칙 |
|---|---|
| "세부 사항을 자세하게 학습하도록 하기보다는" | ❌ 암기 퀴즈·용어 맞히기 중심으로 만들지 않는다. 문법 용어는 결과로 얻는 것이고 입장권이 아니다. |
| "'훈민정음 언해본'과 같은 국어 자료를 바탕으로" | ✅ **진짜 원문 자료**가 게임 판이 된다. 자료를 만지고 비교하는 것이 곧 플레이다. |
| "중세 국어와 현대 국어의 차이를 살펴" | ✅ 핵심 메커닉은 **비교·대조·차이 발견**이다 (틀린 그림 찾기, 번역, 복원). |
| "국어가 변화하는 실체임을 인식" | ✅ 마지막에 "말은 지금도 바뀌고 있다"는 깨달음으로 이어지도록 현재까지 이어지는 흐름을 보여 준다. |
| "국어의 미래를 예측" | ✅ 엔딩 또는 확장 활동: 지금의 말이 500년 뒤 어떻게 보일지 예측하고 만들어 보기 |
| "원리나 규칙을 발견하는 과정을 체험하는 데 중점" (중학교 고려 사항) | ✅ 규칙을 먼저 알려 주지 않고 **사례 → 규칙 발견**(귀납) 순서로 짠다. |
| "훈민정음 창제 정신과 원리" + "디지털⋅정보화 시대 한글의 가치" | ✅ 제자 원리 퍼즐을 천지인 자판처럼 지금의 디지털 생활과 잇는다. |

## 2. 학습 내용 분류 체계

### 2-1. 분류 틀: 두 축 + 맥락 층

```
                     [맥락 층]  왜 만들었나 · 누가 썼나 · 어떻게 퍼졌나 (시대·사회·문화)
                    ┌──────────────────────────────────────────────────────────────┐
  [축 A: 언어 층위]   │  ① 문자   ② 표기   ③ 소리(음운)   ④ 문법   ⑤ 어휘·의미             │
                    └──────────────────────────────────────────────────────────────┘
  [축 B: 학습 깊이]   알아보기 → 읽어 내기 → 비교·규칙 발견 → 현재·미래로 잇기(성찰)
                     (인지)      (해독)       (분석)            (적용·태도)
```

- **축 A (언어 층위)**: 무엇을 배우는가. 교과서의 단원 구성(창제 원리 → 표기 → 음운 → 문법 → 어휘)과 같은 순서다.
- **축 B (학습 깊이)**: 얼마나 깊이 배우는가. 학년 수준을 나누는 기준이 되고, 게임의 단계나 난이도 곡선이 된다.
- **맥락 층**: 사용자가 요청한 "그 당시 조선 시대 맥락"이다. 모든 층위를 감싸며, 게임의 서사와 세계관이 된다.

### 2-2. 축 A — 언어 층위별 학습 내용 상세

#### ① 문자: 훈민정음 창제 원리 (중학교 핵심)

| 하위 내용 | 핵심 사실 | 예시 | 학년 |
|---|---|---|---|
| 창제 정신 | 자주(우리말이 중국과 다름) · 애민(백성이 뜻을 펴지 못함) · 실용(쉽게 익혀 날마다 씀) | 어제 서문 세 문장과 하나씩 대응 | 중 |
| 초성 상형 | 기본자 5자는 발음 기관을 본떴다 | ㄱ(혀뿌리가 목구멍을 막는 모양) · ㄴ(혀가 윗잇몸에 닿는 모양) · ㅁ(입 모양) · ㅅ(이 모양) · ㅇ(목구멍 모양) | 중 |
| 초성 가획 | 소리가 세지면 획을 더한다 | ㄱ→ㅋ / ㄴ→ㄷ→ㅌ / ㅁ→ㅂ→ㅍ / ㅅ→ㅈ→ㅊ / ㅇ→ㆆ→ㅎ | 중 |
| 초성 이체 | 가획 원리와 다르게 만든 글자 | ㆁ(옛이응) · ㄹ · ㅿ(반치음) | 중 |
| 중성 상형 | 하늘·땅·사람을 본떴다 | ㆍ(하늘, 둥근 모양) · ㅡ(땅, 평평한 모양) · ㅣ(사람, 서 있는 모양) | 중 |
| 중성 합성 | 기본자를 합쳐 만든다 | 초출자 ㅗ ㅏ ㅜ ㅓ / 재출자 ㅛ ㅑ ㅠ ㅕ | 중 |
| 종성 | 종성부용초성: 받침은 초성 글자를 다시 쓴다 | 새 글자를 만들지 않음 | 중 |
| 28자 체계 | 초성 17 + 중성 11 = 28자 | 오늘날 24자와 비교: 사라진 4자 ㆍ ㅿ ㆆ ㆁ | 중 |
| 운용 규칙 | 연서(ㅸ) · 병서(각자병서 ㄲ ㄸ ㅃ ㅆ ㅉ ㆅ, 합용병서 ㅺ ㅄ ㅼ ㅽ 등) · 부서(모음 위치) · 성음법(모아쓰기) | ㅸ는 28자에 들지 않고 연서로 만든 글자 | 중~고1 |
| 디지털 연결 | 천지인 자판은 중성 제자 원리를 그대로 쓴 입력 방식이다 | ㅣ + ㆍ = ㅏ | 중 |

#### ③ 소리(음운): 무엇이 사라지고 바뀌었나 (고1~고2)

| 하위 내용 | 핵심 사실 | 예시 | 언제 |
|---|---|---|---|
| ㆍ(아래아) 소실 | 1단계: 둘째 음절 이하에서 ㅡ로 / 2단계: 첫음절에서 ㅏ로 | ᄀᆞᄅᆞ치다 → ᄀᆞ르치다(둘째 음절) → 가르치다(첫음절) | 16세기 / 18세기 (표기는 1933 통일안에서 폐지) |
| ㅸ 소실 | 순경음 [β] → 반모음 w 등 | 수ᄫᅵ → 수이 → 쉬이 | 15세기 중엽 (세조 무렵) |
| ㅿ 소실 | 반치음 [z] 소실 | 아ᅀᆞ → 아ᄋᆞ → 아우 · ᄆᆞᅀᆞᆷ → ᄆᆞᄋᆞᆷ | 16세기 후반 |
| ㆆ 소실 | 주로 한자음·사잇소리 표기용 | 홇 배 · 便뼌安ᅙᅡᆫ | 15세기 후반 |
| ㆁ 변화 | 옛이응 [ŋ] 글자가 ㅇ에 합쳐짐 (소리는 받침 ㅇ으로 남음) | ᄆᆡᇰᄀᆞ노니 | 16세기 무렵 |
| 어두 자음군 | 첫소리에 자음 두세 개 (ㅂ계 ᄠ ᄡ, ㅅ계 ᄯ ᄭ, ㅄ계 ᄢ) | ᄠᅳᆮ(뜻) · ᄡᆞᆯ(쌀) | 된소리로 바뀜 (흔적: 좁쌀·찹쌀·햅쌀의 ㅂ) |
| 성조 | 소리의 높낮이로 뜻 구별 (방점) | — | 16세기 후반 소멸 (일부 방언에 남음) |
| 모음 조화 | 양성(ㆍ ㅗ ㅏ) / 음성(ㅡ ㅜ ㅓ) / 중성(ㅣ)이 엄격하게 어울림 | ᄂᆞᄆᆞᆯ / 사ᄅᆞᄆᆞᆯ vs 므를 | 현대는 많이 무너짐 (의성어·의태어, 어미 '-아/-어'에 흔적) |
| 구개음화 이전 | ㄷ+ㅣ가 그대로 [디] | 디다(지다) · 됴타(좋다) · 텬디(천지) | 17~18세기에 구개음화 |
| 원순모음화 이전 | ㅁㅂㅍ 뒤 ㅡ가 그대로 | 믈(물) · 블(불) · 스믈(스물) | 17세기 말 |

| 하위 내용 | 핵심 사실 | 예시 | 학년 |

| 객체 높임 선어말 어미 | -ᄉᆞᆸ- / -ᅀᆞᆸ- / -ᄌᆞᆸ- (앞소리에 따라 형태가 바뀜). 현대에는 사라지고 '드리다, 여쭈다' 같은 특수 어휘로만 남음 | 듣ᄌᆞᆸ고 **(검증 필요)** | 고2~3 |
| 상대 높임 | 하쇼셔체 '-ᅌᅵ-' | ᄒᆞᄂᆞ니ᅌᅵ다 | 고2~3 |
| 의문문 | 판정 의문 '-가/-아' vs 설명 의문 '-고/-오' / 2인칭 주어 '-ㄴ다' | 이 ᄯᆞ리 너희 죵가 (판정) · 얻논 藥이 므스것고 (설명) · 네 엇뎨 안다 **(검증 필요)** | 고2~3 |
| 명사형 어미 | '-옴/-움'이 중심 | ᄡᅮ메(ᄡᅳ-+-움+에) | 고2~3 |
| ㅎ 종성 체언 | 일부 명사가 조사 앞에서 ㅎ을 드러냄 | 내ㅎ+이 → 내히 · 하ᄂᆞᆯㅎ | 고2~3 (현대 흔적: 암탉, 수캐, 안팎) |

#### ⑤ 어휘·의미: 말의 뜻은 어떻게 변했나 (중~고 모두, 흥미 유발에 가장 좋음)

## 4. 핵심 원문 자료 후보와 그 안에 든 학습 요소

### 4-1. 「세종어제훈민정음」(언해본) 서문 — 가장 우선

> 나랏 말ᄊᆞ미 中듕國귁에 달아 文문字ᄍᆞᆼ와로 서르 ᄉᆞᄆᆞᆺ디 아니ᄒᆞᆯᄊᆡ
> 이런 젼ᄎᆞ로 어린 百ᄇᆡᆨ姓셩이 니르고져 홇 배 이셔도
> ᄆᆞᄎᆞᆷ내 제 ᄠᅳ들 시러 펴디 몯ᄒᆞᇙ 노미 하니라
> 내 이ᄅᆞᆯ 爲윙ᄒᆞ야 어엿비 너겨 새로 스믈여듧 字ᄍᆞᆼᄅᆞᆯ ᄆᆡᇰᄀᆞ노니
> 사ᄅᆞᆷ마다 ᄒᆡᅇᅧ 수ᄫᅵ 니겨 날로 ᄡᅮ메 便뼌安ᅙᅡᆫ킈 ᄒᆞ고져 ᄒᆞᇙ ᄯᆞᄅᆞ미니라
>
> **(검증 필요: 방점 생략, 글자 하나하나 영인본과 대조)**

이 108자 안에 고1 학습 요소가 거의 다 들어 있다. 하나의 원문으로 게임 전체를 만들 수 있다는 뜻이다.

| 원문 부분 | 들어 있는 학습 요소 | 층위 |
|---|---|---|
| 나랏 말ᄊᆞ미 | 관형격 'ㅅ'(무정 명사) · 이어적기(말ᄊᆞᆷ+이) · ㆍ | 문법·표기·소리 |
| 中듕國귁에 달아 | 동국정운식 한자음 · 비교의 '에'(~와 달라) | 표기·문법 |
| 文문字ᄍᆞᆼ와로 서르 ᄉᆞᄆᆞᆺ디 | 서르→서로(모음 변화) · 디→지(구개음화 이전) · 사라진 말 ᄉᆞᄆᆞᆺ다(통하다) | 소리·어휘 |
| 어린 百姓 | **어리다 = 어리석다** (의미 이동) | 어휘 |
| 니르고져 홇 배 | 니르다→이르다 · ㆆ | 소리·표기 |
| 제 ᄠᅳ들 시러 펴디 | 어두 자음군 ᄠ · 이어적기 · 시러(능히) | 소리·표기·어휘 |
| 노미 하니라 | **놈 = 평범한 사람** · **하다 = 많다** | 어휘 |
| 어엿비 너겨 | **어엿브다 = 불쌍하다** | 어휘 |
| 스믈여듧 字 | 28자 · 스믈→스물(원순모음화) | 문자·소리 |
| ᄆᆡᇰᄀᆞ노니 | ㆁ(옛이응) · ᄆᆡᇰᄀᆞᆯ다→만들다 | 문자·어휘 |
| 수ᄫᅵ 니겨 | ㅸ(순경음 비읍) · 수ᄫᅵ→쉬이 | 문자·소리 |
| ᄡᅮ메 | 어두 자음군 ᄡ · 명사형 '-움' | 소리·문법 |
| 便뼌安ᅙᅡᆫ킈 | ㆆ · 동국정운식 한자음 | 표기 |
| ᄯᆞᄅᆞ미니라 | ㅅ계 자음군 ᄯ · ㆍ | 소리 |

창제 정신과도 대응한다: 첫 문장은 **자주**, 둘째·셋째 문장은 **애민**, 마지막 문장은 **실용**.

### 4-2. 「용비어천가」 제2장 — 보조 자료

> 불휘 기픈 남ᄀᆞᆫ ᄇᆞᄅᆞ매 아니 뮐ᄊᆡ 곶 됴코 여름 하ᄂᆞ니
> ᄉᆡ미 기픈 므른 ᄀᆞᄆᆞ래 아니 그츨ᄊᆡ 내히 이러 바ᄅᆞ래 가ᄂᆞ니 **(검증 필요)**

| 원문 부분 | 학습 요소 |
|---|---|
| 불휘 기픈 | 주격 Ø(ㅣ 뒤) · 이어적기 |
| 남ᄀᆞᆫ | 특수한 곡용 나모 → 남ㄱ+ᄋᆞᆫ |

| 므른 | 원순모음화 이전(믈) |
| 내히 | ㅎ 종성 체언(냏) |
