## 1. 결론부터

- **「세종어제훈민정음」 서문(언해, 『월인석보』 권1, 1459) 8구절은 확정**했다(확실도 ◎).
  - 기준 본문인 지학사 공통국어2 132쪽을 **PDF 글자 층(한양 PUA)에서 직접 뽑아** 위키문헌·위키백과 입력본과 맞대니 방점까지 **118자 모두 같다(100%)**.
  - 방점·한자음을 싣지 않은 세종한글고전(허웅 역주 『월인석보 제1』)과는 한자음을 빼고 방점을 무시하면 **108자 모두 같다(100%)**. 글자 모양(ᄊᆡ·ᄆᆡᇰ·ᄠᅳ·ᄡᅮ·ᅇᅧ·ᄫᅵ·ᅙᅡᆫ 등)은 독립 자료 둘 이상이 같다.
  - 위키백과 「훈민정음 언해」 문서와는 98.31%: 그 문서가 `百ᄇᆡᆨ`의 거성 점과 `:몯`의 상성 점을 빠뜨렸다. 교과서와 중2-2 138쪽 원본 사진(재구성)에서 두 점을 눈으로 확인했다.
  - 교과서 화면 글꼴은 ㆎ를 ㅣ처럼 그린다(`ᄊᆡ`가 `씨`, `ᄆᆡᇰ`이 `밍`, `百ᄇᆡᆨ`이 `빅`처럼 보임). 그래도 **글자 층은 ㆎ**이고 독립 자료도 모두 ㆎ라서 ㆎ로 적는다. 화면 모양만 보고 고치면 안 된다.
- **『훈민정음』 해례 한문(제자해·합자해·종성해·용자례), 정인지 서 구절, 어제 서문 한문**은 쓸 부분만 블록으로 확정했다.
  - 제자해 앞부분(상형·가획·이체·ㆍㅡㅣ·삼재)은 국사편찬위원회 우리역사넷 원문과 맞아 ◎이다.
  - ㅗㅏㅜㅓ 합성, 초출·재출, 합자해, 종성해, 용자례는 공공 기관의 디지털 원문을 찾지 못했다. 서로 다른 입력본 셋(위키문헌 한국어판·중국어판, abkai.net)이 맞아 ○로 둔다.
- **교과서에 실리지 않은 것**: 세 교과서 모두 해례의 한문 원문은 싣지 않았다. 중2-2는 현대어 번역이나 활동으로만 다룬다(137쪽 정인지 구절, 140~143쪽 상형·가획·합성). 그래서 해례 블록의 교과서 칸은 '원문 미수록'으로 적는다.
- **못 본 것**: 해례본(간송본) 원본 사진을 글자 단위로 보지 못했다. 그래서 `加畫`/`加劃`, 이체자 자형, 용자례 방점은 입력본끼리만 맞대었다. 국립국어원 『알기 쉽게 풀어 쓴 훈민정음』(2008) PDF는 그림 파일이라 용자례 방점 몇 개만 눈으로 맞춰 보았다. 화법과 언어 교과서는 서문을 통째로 싣지 않고 낱말 예시만 싣는다(204쪽).
- **데이터에서 뺀 것(△·생략)**: 「세종어제훈민정음」 제목 줄(한자음 방점을 독립 자료 둘로 맞추지 못함), 용자례 중 방점이 자료마다 다른 낱말이 든 묶음(ㆍ의 ᄀᆞ래, ㅕ의 뎔·벼, ㅑ·ㅠ 묶음 등). §8에 목록이 있다.

### 2-2. 방침

1. **기준 본문 = 지학사 교과서 통용형.** 서문은 공통국어2 132쪽 글자 층을 그대로 쓴다. 방점·한자음·글자 모양 모두 이 판을 따른다.
2. 교과서에 없는 한문(해례·정인지 서·어제 서문 한문)은 **해례본 계열 입력본 다수형**을 기준으로 한다. 공공 기관 원문(우리역사넷)이 있는 구절은 그것과 맞아야 ◎이다.
3. **독립 자료 둘 이상이 같은 글자만** 블록에 넣는다. 같은 입력에서 나온 사본(위키문헌·언해 ↔ 위키백과·훈)은 하나로 센다.
4. 한자 **이체자**(為/爲, 彂/發, 𠕅/再, 䨱/覆, 𡈽/土, 㸃/點, 軽/輕 …)는 통용 정자로 적는다. 비교 때는 같은 글자로 본다(대조 규칙 R6에 목록이 있음). 원본 자형을 보여 줄 때는 '이본 노트'로 다룬다.
5. 원본에는 띄어쓰기와 현대 구두점이 없다. 언해 줄은 **붙여 쓴다**. 한문 줄은 구두점 대신 **구절 경계에만 빈칸**을 둔다. 빈칸은 편집 표시일 뿐 글자가 아니다(대조 도구는 빈칸·구두점을 지우고 비교한다).
6. 블록은 구절(절) 단위로 잘게 나눈다. 해례에서 일부만 뽑은 블록은 블록 아래 `범위:`에 앞뒤를 적는다. 뽑은 범위 안의 글자는 하나도 빼거나 고치지 않았다.
7. 현대어 풀이는 모두 **새로 썼다**(§4·§5). 교과서·번역서·위키백과의 번역 문장은 옮기지 않았다.

## 3. 데이터 표기 규칙 (원문 줄에 쓰는 표기)

C1(옛한글 조합기)이 그대로 읽는 표기다. 원문 줄(`> ` 줄)에는 이 표기만 쓴다.

| 표기 | 뜻 | 예 |
|---|---|---|
| 현대 한글 음절 | 현대 완성형으로 나타낼 수 있는 음절은 그대로 쓴다 | `나`, `랏`, `젼`, `뼌`, `킈`, `몯`, `듧` |
| `[초성중성종성]` | 현대 완성형에 없는 **한 음절**. 대괄호 안에 호환 자모를 초성·중성·(종성) 순으로 2~3자 쓴다 | `[ㅆㆍ]`=ᄊᆞ, `[ㅎㆍㅭ]`=ᄒᆞᇙ, `[ㄷㅠㆁ]`=듀ᇰ |
| 대괄호 안의 겹자음 | 각자병서·합용병서·연서는 **호환 자모 한 글자**로 쓴다 | ㅆ ㆀ(ᅇ) ㆅ(ᅘ) ㅄ ㅳ(ᄠ) ㅶ(ᄧ) ㅼ(ᄯ) ㅺ(ᄭ) ㅴ(ᄢ) ㅵ(ᄣ) ㅸ(ᄫ) |
| 대괄호 안의 옛 모음 | ㆍ(아래아), ㆎ(ᆡ) 등 호환 자모 한 글자 | `[ㅆㆎ]`=ᄊᆡ, `[ㅁㆎㆁ]`=ᄆᆡᇰ |
| 대괄호 안의 옛 종성 | ㆁ(ᇰ), ㅭ(ᇙ, ㄹㆆ), ㄺ, ㅩ(ᇌ, ㄹㄱㅅ), ㅿ 등 호환 자모 한 글자 | `[ㅎㅗㅭ]`=호ᇙ, `[ㄷㆍㅩ]`=ᄃᆞᇌ |
| `·` (U+00B7) | 바로 뒤 음절의 **거성(1점)** | `나·랏` |
| `:` (U+003A) | 바로 뒤 음절의 **상성(2점)** | `:말`, `:[ㅎㆎ]` |
| 점 없음 | 평성 | `서르` |
| `{漢\|음}` | 한자와 그 옆의 동국정운식 한자음(루비). 음에도 방점·대괄호를 쓴다 | `{中\|[ㄷㅠㆁ]}`, `{國\|·귁}`, `{安\|[ㆆㅏㄴ]}`, `{字\|·[ㅉㆍㅇ]}` |
| 한문 속 낱자 | 해례 한문 안의 자모 이름(ㄱ, ㆆ, ㅿ, ㆍ 등)은 대괄호 없이 **호환 자모 한 글자**로 쓴다. 음절이 아니라 글자 자체다 | `牙音ㄱ`, `ㅇ而ㆆ` |
| 빈칸 | 한문 줄의 구절 경계(편집 표시). 언해 줄에는 쓰지 않는다 | `ㅋ比ㄱ 聲出稍厲 故加畫` |

- 동국정운식 한자음의 끝소리 **ㅇ(소릿값 없는 이응)** 과 **ㆁ(옛이응)** 을 구별한다. `字·[ㅉㆍㅇ]`, `爲·윙`은 ㅇ, `中[ㄷㅠㆁ]`, `姓·[ㅅㅕㆁ]`은 ㆁ이다(교과서 글자 층 U+11BC / U+11F0). 처음 옮길 때 字를 ㆁ으로 잘못 적었는데, 대조 도구가 잡아내 고쳤다(§6).
- 방점은 **음절 바로 앞**에 붙인다. 원본에서 점은 글자 왼쪽에 찍히고, 유니코드 원문에서는 음절 뒤에 U+302E/302F로 붙는다. 이 문서는 교과서처럼 앞붙임으로 통일한다.
- C1에 바라는 점(확인 요청): 대괄호 밖의 호환 자모 한 글자(`ㄱ`, `ㆆ`, `ㆍ`)는 조합하지 않고 그대로 낸다. 대괄호 안 중성 `ㆎ`는 첫가끝 U+11A1로 조합한다.

#### 풀이 · 새로 씀 ― 중학교판 현대어 서문 (s9 중학교판용, 原文 아님)

> **새로 쓴 현대어 풀이** (원문을 옮긴 것이 아니라, 원문의 뜻을 오늘 말로 다시 짠 글. 화면에는 `풀이` 표지로만 보인다)
>
> 우리말은 중국말과 소리부터 다르다. 그런데 글은 중국 글자인 한자를 빌려 써 왔으니, 말과 글이 서로 맞아떨어지지 않는다. 그래서 글을 배우지 못한 백성은 꼭 하고 싶은 말이 있어도 끝내 그 마음을 글로 펼쳐 보이지 못하는 일이 많다. 나는 그것이 늘 안타까웠다. 그래서 스물여덟 글자를 새로 만들었다. 누구든 쉽게 배워 날마다 편하게 쓰기를 바랄 뿐이다.

## 6. 대조 방법과 결과

### 6-1. 방법

1. **교과서 판독**: 교과서 PDF는 일반 추출로는 옛한글이 깨진다. 글자 층에는 한컴 계열 **한양 PUA** 코드가 들어 있다. 이것을 `hypua2jamo`(pip)로 첫가끝 자모열로 풀고, 글자 상자의 위치(기준선 y, x)로 줄을 다시 세웠다. 결과는 200·400·700·1200dpi 그림 판독과 하나하나 맞대었다. 방점 ':'과 '·'은 교과서 글자 층에 앞붙임으로 들어 있다. 쓴 코드(PyMuPDF + hypua2jamo):
   ```python
   import fitz, hypua2jamo
   p = fitz.open(PDF)[131]                    # 공통국어2 132쪽
   s = p.rect.width / 1275                    # 150dpi 그림 좌표 → PDF 좌표
   clip = fitz.Rect(380*s, 270*s, 1100*s, 615*s)   # 서문 본문 상자
   chars = [(ch['bbox'][3], ch['origin'][0], ch['c'])
            for b in p.get_text('rawdict', clip=clip)['blocks'] for l in b.get('lines', [])
            for sp in l['spans'] if sp['size'] >= 9 for ch in sp['chars']]
   chars.sort(); lines = []
   for c in chars:                            # 기준선이 12pt 안이면 같은 줄
       if lines and abs(c[0] - lines[-1][0]) < 12: lines[-1][1].append(c)
       else: lines.append([c[0], [c]])
   for _, L in lines:
       print(''.join(hypua2jamo.translate(c[2]) for c in sorted(L, key=lambda z: z[1])))
   ```
2. **웹 자료**: `curl`로 원문을 받아 위키 틀·HTML만 걷어 내고 `design/research/source_cache/`에 둔다. 글자는 손대지 않았다. 세종한글고전은 한양 PUA라 같은 방법으로 풀었다.
3. **글자 단위 대조**: `tools/compare_orig.py`가 두 입력을 정규화한다(규칙 R1~R9는 실행할 때마다 출력). 그다음 **음절(방점 포함) 단위 토큰열**을 `difflib.SequenceMatcher`로 맞대어 일치율(2×같은 글자/(A+B))과 차이 줄을 낸다. 리서치 문서의 블록은 데이터 표기를 풀어 비교한다(`문서.md::블록id`). 웹 자료는 `파일::시작..끝`으로 해당 구절만 잘라 비교한다.
4. **다시 돌리기**: `source_cache/r1_jobs.tsv`가 모든 대조 작업 목록이다.
   ```
   python tools/compare_orig.py --batch design/research/source_cache/r1_jobs.tsv
   ```

## 8. 해석이 갈리는 곳 (채점하지 않음) · 확인 못 한 것

### 8-1. 해석이 갈리는 곳 (`해석` 표지로만 보이고 채점하지 않는다)

- **SEOMUN4 `·노·미`(者)**: 예전부터 '사람'으로 풀어 왔다. '것·경우'로 보자는 주장도 있다(정요일 2008, 위키백과 「훈민정음 언해」 각주가 소개). 새로 쓴 풀이는 '사람'을 썼다.
- **SEOMUN1~2 '中國'·'文字'**: 文字를 '한자'로 보는 풀이가 보통이다. '중국의 글(한문)'로 넓게 보는 풀이, '말소리가 중국과 다르다'는 음운 쪽 풀이도 있다. 풀이 문장은 '한자로 적어서는'으로 두었다.
- **SEOMUN3 '어린'**: '어리석은'이 통설이다(교과서 날개). 다만 '글을 모르는'으로 옮기는 풀이도 많다. 새로 쓴 풀이는 '글을 모르는'을 썼다.
- **SEOMUN5 `:어엿·비`**: '불쌍히·가엾이'가 통설이다(화언 202쪽 의미 변화 활동). 새로 쓴 풀이는 '가엾고 딱하게'를 썼다.
- **SANG-N `上腭`**: '윗잇몸'으로 보는 풀이(교과서 140쪽 활동)와 '입천장'으로 보는 풀이가 있다. 풀이에서는 둘을 함께 적었다.
- **CHEON·JI·IN의 子·丑·寅**: 성리학 우주론(하늘은 자시, 땅은 축시, 사람은 인시에 열림)을 빌린 비유다. 시간 개념으로 채점하지 않는다.
- **JIJ-ZI `不終朝`**: '아침나절이 끝나기 전에'가 낱말 뜻에 가깝다. '아침이 오기 전에'처럼 옮기는 경우도 있다. 새로 쓴 풀이는 앞의 뜻을 썼다.
- **ㆍ의 소리값**(CHEON 풀이의 '소리가 깊다'): 정확한 음가는 학설이 갈린다. spec §12대로 채점하지 않는다.
- **HJ-GAKJA `소·다爲覆物`**: '엎다/쏟다' 중 어느 쪽으로 옮길지 갈린다. 풀이에서는 '엎다'를 썼다.
