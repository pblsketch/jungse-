## 0. 설계 출발점: 중세국어 학습 내용의 "뼈대"는 무엇인가

시리즈 원칙 P2("내용의 뼈대 = 핵심 동사의 모양")에 따라 먼저 뼈대를 한 문장으로 적는다. 중세국어 학습 내용에는 성격이 다른 뼈대가 **세 개** 있다.

| 뼈대 | 한 문장 | 어울리는 핵심 동사 | 어울리는 장르 | 주 대상 |
|---|---|---|---|---|
| **① 생성 체계** | 적은 수의 기본 글자에 규칙(상형·가획·합성·모아쓰기)을 더해 모든 글자를 만든다 | 본뜨다 · 더하다 · 모으다 | 제작(크래프팅) 퍼즐 | 중1~3 |
| **② 해독** | 낯선 표기로 적힌 진짜 문헌을 규칙을 찾아내며 읽어 낸다 | 읽어 내다 · 옮기다 | 해독 어드벤처 (Chants of Sennaar형) | 고1 |
| **③ 변환** | 같은 말이 규칙의 연쇄를 거쳐 오늘날의 말이 되었다 | 흘려보내다 · 거슬러 오르다 | 규칙 파이프라인 퍼즐 | 고1~고2 |

> 음운 해전 결정 0010의 교훈: **한 게임 = 한 초점.** 세 뼈대를 한 게임에 다 넣으면 동사가 셋이 되어 초점이 흐려진다. 그래서 아래 콘셉트는 뼈대 하나씩을 중심에 두고, 통합안(E)은 위험을 함께 적었다.

## 1. 학생이 어려워하는 점 → 게임 장치 (시리즈 표준 첫 표)

| 학생이 어려워하는 점 | 왜 어려운가 | 게임 장치 |
|---|---|---|
| 옛글자(ㆍ ㅿ ㆆ ㅸ)가 **무섭다**, 읽는 법을 모른다 | 처음 보는 기호라서. 도산 검토에서 하위권 페르소나가 "ᅀ 이 세모 글자 어떻게 읽음? 무서움"이라고 함 | 옛글자가 처음 나올 때 **도감 카드 + 소리 단서 한 줄**. 낯선 글자를 "괴물"이 아니라 "모을 것"으로 만든다 |
| 원문이 **외계어처럼 보여** 읽기를 포기한다 | 이어적기·띄어쓰기 없음·한자음 표기가 한꺼번에 나온다 | 원문을 **한 구절씩 열어 가는 해독 구조**. 아는 말(나라·말·백성)부터 불이 켜진다 (Chants of Sennaar의 "맥락으로 추측 → 확정") |
| 제자 원리를 **외우기만** 한다 (상형·가획·이체 용어 암기) | 원리를 직접 써 본 적이 없다 | **직접 만들게** 한다. 발음 기관 단면도를 보고 획을 긋고, 획을 더해 새 글자를 만든다 |
| 주격 조사 '이/ㅣ/Ø' 같은 규칙이 **추상적**이다 | 표로만 배운다 | 사례 카드를 모아 **규칙을 스스로 발견**한다 (귀납). 교육과정 "원리나 규칙을 발견하는 과정을 체험" |
| 이어적기·8종성법을 **틀린 맞춤법**으로 오해한다 | 현대 맞춤법을 기준으로 본다 | "소리 나는 대로 적는 다른 원리"를 체험: 같은 말을 15세기 방식·현대 방식으로 **둘 다 적어 보게** 한다 |
| 방점이 무엇인지 **감이 안 온다** | 소리의 높낮이를 들어 본 적이 없다 | 방점을 **음높이 막대**로 시각화(점 0·1·2 = 낮음·높음·낮다가 높음). 소리 재생 여부는 §6에서 결정 |
| 변화의 **시기가 뒤섞인다** (ㆍ는 언제? 구개음화는 언제?) | 연도만 외운다 | 연도가 아니라 **순서**(상대 연대)로 다룬다. 변화 규칙을 놓는 순서가 맞아야 현대어가 나온다 |
| 의미 변화 단어(어리다·어엿브다)를 **외우기만** 한다 | 맥락 없이 목록으로 배운다 | **오해 장면**: 현대 뜻으로 읽으면 이야기가 이상해지는 순간을 겪게 한다 ("어린 백성"을 '아기 백성'으로 읽으면 생기는 웃긴 장면) |
| **왜 배우는지** 모른다 | 지금 생활과 끊겨 있다 | 연결 고리: 천지인 자판, 좁쌀·찹쌀의 ㅂ, 암탉·수캐의 ㅎ, "말은 지금도 바뀐다"는 엔딩 |
| 창제 정신을 **문장으로만** 외운다 (자주·애민·실용) | 그 시대 사람의 처지를 겪어 보지 않았다 | 글을 몰라 곤란을 겪는 백성 NPC의 문제를 **새 글자로 해결**하는 경험 (절차적 수사학) |

## 2. 겨냥할 오개념 초안 (→ `01_자료_사실확인`에서 검증 후 확정)

| # | 오개념 | 바른 이해 (검증 필요) | 게임에서 다룰 곳 |
|---|---|---|---|
| M1 | 집현전 학자들이 한글을 만들었다 | 세종이 직접 만들었다는 친제설이 유력하다. 집현전 학자들은 『훈민정음』 해례를 집필했다 | 서사 설정, NPC 역할 배치 |
| M2 | '훈민정음'과 '한글'은 처음부터 같은 이름이다 | '훈민정음'은 문자 이름이자 책 이름이다. '한글'은 20세기 초에 생긴 이름이다 | 알아 두기 카드 |
| M3 | 28자에 ㅸ이 들어 있다 | ㅸ은 연서로 만든 글자이고 28자에 들지 않는다 | 도감 분류 |
| M4 | ㄹ·ㆁ·ㅿ도 가획자다 | 이 셋은 이체자다 | 제작 퍼즐 함정 |
| M5 | 이어적기는 맞춤법을 몰라서 생긴 것이다 | 소리 나는 대로 적는 표기 원리다 | 두 방식으로 적어 보기 |
| M6 | 방점은 강세나 장단을 나타낸다 | 성조(소리의 높낮이)를 나타낸다 | 음높이 막대 |
| M7 | 중세에도 주격 조사 '가'가 있었다 | 15세기에는 '이/ㅣ/Ø'만 쓰였다. '가'는 그 뒤에 나타났다 | 규칙 발견 퍼즐 |
| M8 | "어린 百姓" = 나이 어린 백성 | 어리다 = 어리석다 (의미 이동) | 오해 장면 |
| M9 | ㆍ는 'ㅏ'와 같은 소리였다 | 독자적 모음이다. 소실 과정에서 둘째 음절 이하는 주로 ㅡ로, 첫음절은 주로 ㅏ로 바뀌었다 (정확한 음가는 학설이 갈려 **채점하지 않음**) | 해석 카드 |
| M10 | 한글은 반포 직후 곧바로 널리 쓰였다 / 언문이라 아무도 쓰지 않았다 | 양극단 모두 틀렸다. 언해 사업, 궁중·여성·평민의 편지를 통해 점차 퍼졌다 | 맥락 카드 |
| M11 | 세종은 한자를 없애려고 한글을 만들었다 | 백성의 의사 표현과 한자음 표기 정리(『동국정운』)라는 목적이 함께 있었다. 한자를 대체하려 한 것이 아니다 | 서사 대사 |

## 3. 콘셉트 아이디어 5개

### 안 A. 「스물여덟 자의 공방」 — 제자 원리 크래프팅 퍼즐 [뼈대 ①]

| 항목 | 내용 |
|---|---|
| 한 줄 | 1443년, 궁 안 비밀 공방의 견습생이 되어 **발음 기관을 보고 글자를 직접 만들고**, 그 글자로 백성의 말을 적어 준다. |
| 대상·성취기준 | 중1~3 · [9국04-01] (해설: "훈민정음 창제 정신과 원리", "디지털⋅정보화 시대 한글의 가치") |
| 핵심 동사 | 본뜨다 → 더하다 → 모으다 |
| 코어 루프 | **30초**: 단면도에서 소리를 내 보고(혀·입술 움직임) 붓으로 획 긋기 → **5분**: 기본자 → 가획 → 이체로 한 계열 완성 → **한 판**: 백성의 의뢰("우리 집 소 이름을 적어 주시오")를 새 글자로 모아 써서 해결 |
| 다루는 학습 카드 | L01 상형 · L02 가획·이체 · L03 천지인 합성 · L04 28자 · L05 창제 정신 · L06 모아쓰기·병서·연서 · L19 용자례 어휘 |
| 시대 맥락 | 한자를 몰라 억울함을 풀지 못하는 백성(창제 정신의 '애민'), 반대 상소(1444)를 둘러싼 논쟁, 반포(1446) |
| 기억에 남을 한 장면 | **음운 해전에서 뺀 "소리가 글자가 되는 순간"을 살린다.** 단면도 속 혀뿌리 선이 먹선으로 굳어 〈ㄱ〉이 되고, 붓이 한 획을 더 그으면 〈ㅋ〉이 된다 |
| 결과물(제출) | "나의 스물여덟 자 도감" + 내가 적어 준 백성의 말 한 줄 |
| 디지털 연결 | 엔딩: 휴대폰 **천지인 자판**이 중성 제자 원리(ㆍㅡㅣ)를 그대로 쓴다는 발견 |
| 재사용 자산 | 음운 해전 입안 단면도 SVG·자질 데이터·"따라 해 보기" 문구 |
| 참고 게임 | Heaven's Vault(기본 글자 합성), Type:Rider·Metamorphabet(글자 모양이 놀이 공간) |
| 점검 질문 | "제자 원리를 빼면 이 게임은 성립하지 않는다. 글자를 만드는 규칙 자체가 조작이기 때문이다." ✅ |
| 위험 | ① 세종·집현전의 역할 허구화 (M1) → 플레이어는 가상의 견습생으로 두고, 세종의 말은 어제 서문에 근거한 것만 쓴다 ② 음운 해전과 겹칠 위험 → **"소리는 음운 해전, 글자는 이 게임"**으로 역할을 나누고 표기도 `/ㄱ/`(소리)와 〈ㄱ〉(글자)로 구별한다 ③ 고등학생에게는 쉬울 수 있다 |

### 안 B. 「활자 한 벌」 — 언해 조판소 규칙 발견 퍼즐 [뼈대 ②의 '쓰기' 쪽]

| 항목 | 내용 |
|---|---|
| 한 줄 | 1459년 『월인석보』를 찍기 직전의 조판소. 견습 조판공이 되어 **빈 판에 알맞은 활자를 골라 박으며** 15세기 표기·문법 규칙을 스스로 알아낸다. |
| 대상·성취기준 | 고1 · [10공국2-04-01] |
| 핵심 동사 | 고르다 · 박다 |
| 코어 루프 | **30초**: 빈 활자 자리에 들어갈 활자를 상자에서 고름 (예: 사ᄅᆞᆷ+[이/ㅣ/Ø]) → **5분**: 한 면을 다 채우면 판을 찍어 종이에 인쇄(확정의 쾌감) → **한 판**: 면이 쌓여 책 한 권 |
| 규칙 발견 방식 | 처음에는 활자 상자에 사례만 있고 규칙은 없다. 여러 면을 짜면서 "자음 뒤엔 '이', 모음 뒤엔 'ㅣ'…"를 **학생이 규칙 카드로 정리**한다. 맞힌 규칙 카드는 다음 면에서 도우미가 된다 |
| 다루는 학습 카드 | L07 이어적기 · L08 8종성법 · L09 방점 · L10 동국정운식 한자음 · L14 주격 조사 · L15 관형격 · (모음 조화에 따른 조사) |
| 시대 맥락 | 활자 인쇄 (『월인천강지곡』·『석보상절』은 활자본 **(검증 필요)**), 언해 사업, 불경과 교화서를 백성의 말로 옮기는 일 |
| 결과물 | "내가 짠 언해본 한 면" (진짜 원문과 같아짐) |
| 시리즈 원칙 지키기 | ⚠️ "틀린 원고 교정" 방식은 **틀린 옛말을 보여 주게 되므로 쓰지 않는다**(오정보 효과). 대신 **빈칸을 채우는 조판** 방식으로 해서 완성품은 항상 진짜 원문이 된다 |
| 참고 게임 | 사씨남정기의 빈칸 복원(묶음 확정·부분 피드백), A Little to the Left(정리의 쾌감) |
| 점검 질문 | "표기·문법 규칙을 빼면 활자를 고를 근거가 없어 게임이 성립하지 않는다." ✅ |
| 위험 | 문법 규칙이 많아 단조로운 '빈칸 채우기'가 될 수 있다 → 면마다 새 기믹 하나 (예: 2면은 모음 조화 상자, 3면은 방점 먹칠) |

### 안 C. 「말의 강」 — 국어 변화 규칙 파이프라인 퍼즐 [뼈대 ③]

| 항목 | 내용 |
|---|---|
| 한 줄 | 15세기 낱말을 **시간의 강에 띄워 보내며**, 나루(시대)마다 알맞은 변화 규칙 돌을 놓아 오늘날의 말로 무사히 도착하게 한다. 반대로 오늘날 말을 거슬러 올려 15세기 모습을 복원하기도 한다. |
| 대상·성취기준 | 고1~2 · [10공국2-04-01] · [12화언01-01] |
| 핵심 동사 | 흘려보내다 · 거슬러 오르다 |
| 코어 루프 | **30초**: 변화 규칙 돌 하나 놓기 (예: "ㆍ→ㅡ (둘째 음절)") → **5분**: 낱말 하나가 강을 따라 흘러가며 모양이 바뀌는 연출, 현대어 나루에 맞게 도착하면 성공 → **한 판**: 낱말 여러 개를 **같은 규칙 배치로** 동시에 통과시키기 (한 규칙이 여러 낱말에 동시에 작용한다는 체계성 체험) |
| 예시 | ᄆᆞᅀᆞᆷ → [ㅿ 소실] → ᄆᆞᄋᆞᆷ → [ㆍ→ㅡ, 둘째 음절] → ᄆᆞ음 → [ㆍ→ㅏ, 첫음절] → 마음 / 디다 → [구개음화] → 지다 / 믈 → [원순모음화] → 물 |
| 판정 원칙 | 연도가 아니라 **순서(상대 연대)**로만 판정한다. 정확한 연도는 알아 두기 카드에만 둔다 (채점하지 않음) |
| 다루는 학습 카드 | L11 소실 문자 · L12 어두 자음군 · L13 구개음화·원순모음화 · L18 의미 변화(의미 나루) · L20 미래 예측 |
| 시대 맥락 | 강가의 나루마다 그 시대 문헌 한 줄(언해본 → 16세기 언간 → 근대 문헌)을 비석처럼 세워 둔다 |
