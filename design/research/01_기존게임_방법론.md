## 2. 학습 게임 설계 이론 (실제로 쓴 것만)

| 이론 | 핵심 | 시리즈에서 어떻게 썼나 | 중세국어 게임에 적용하면 |
|---|---|---|---|
| **내재적 통합** (Habgood & Ainsworth) | 학습 내용을 핵심 조작 안에 넣는다. 점검 질문: **"내용을 빼도 게임이 성립하는가? 성립하면 초콜릿 입힌 브로콜리"** | 모든 기획안 첫 줄. 음운 해전: "문법 문제를 곱셈 문제로 바꿔도 굴러가면 실패" | 제자 원리·표기 규칙·변화 규칙 자체가 조작이어야 한다. 퀴즈를 덧붙이는 방식은 쓰지 않는다 |
| **MDA** | 목표 정서(미학)를 먼저 정하고 역으로 규칙을 짠다 | 사씨: 1순위 발견+도전 / 도산: 발견+감각+몰두 | 목표 정서 후보: **"낯선 글자가 읽히기 시작하는 쾌감"**(해독), "내 손으로 글자를 만드는 뿌듯함"(창조) |
| **절차적 수사학** (Bogost) | 규칙이 무엇을 주장하는지 따진다 | 영웅: 여성 경로에만 의심 게이지 → 당대 여성의 제약 체험 | "백성이 뜻을 펴지 못한다"는 문제를 규칙으로 체험시키면 창제 정신(애민)이 저절로 전달된다 |
| **인지 부하** (Sweller, Mayer) | 내용이 어려우면 조작은 최소로 | "조작 동사는 하나, 타이머·반사신경 없음" | 옛글자 자체가 부담이므로 조작은 탭·끌기 하나로 한다 |
| **Gee의 어항 원리** | 핵심 변수만 남긴 축소판부터 | 첫 장 인물 3명, 첫 곡 시어 2개 | 첫 화면은 기본자 5자, 원문은 한 구절부터 |
| **몰입·난이도 곡선** (Hamari) | **도전은 학습을 예측하지만 몰입감(그래픽)은 무관하다** | 난이도 축 명시, 선택형 난이도 | 그림보다 도전의 적절성에 공을 들인다 |
| **자기결정성** | 자율성·유능감·관계성 | 이름 짓기, 조사 순서 선택. 단 원작 결말은 못 바꿈 | 탐구 순서는 학생이 고르고, 사실(원문)은 바꾸지 못하게 한다 |
| **스캐폴딩·페이딩** | 풀이 예시 → 단계적으로 도움을 걷어 냄 | 도산: 1곡은 한 칸만 → 11곡은 도움 없이 | 첫 규칙은 시범을 보여 주고, 다음은 스스로 하게 한다 |
| **인출 연습·간격** | 다시 보여 주지 말고 떠올리게 한다 | 2차시 사이 간격, 장 끝 물음 | 2부 첫머리에 1부 글자를 보지 않고 떠올리기 |
| **디브리핑("게임 샌드위치")** | 학습은 게임 뒤 정리에서 일어난다 | 45분 중 8~10분 디브리핑, 결과 화면 캡처 제출 | "지금 우리말도 바뀌고 있는 것 하나 찾기"로 마무리 |
| **오정보 효과·출처 감시** (Marsh & Fazio) | 허구 속 오류는 기억에 섞인다. 막는 것은 일반 경고가 아니라 구체적 교정이다 | **사실/해석/허구 표지 체계**, what-if 금지 | ⚠️ "틀린 표기 고치기" 같은 장치는 **틀린 옛말을 보여 주게 되므로 위험하다**. 빈칸 채우기·조립 방식으로 바꾼다 |
| **유추·구조 사상** (Gentner) | 겉모양이 아니라 관계로 이름 붙인다 | 시어를 관계 문장으로 | "ㄴ→ㄷ→ㅌ : ㅁ→ㅂ→ㅍ" 같은 가획 계열의 평행 구조 비교 |
| **자기 설명** (Johnson & Mayer) | **쓰게 하지 말고 고르게 하라** | 근거 시구 고르기 | 문법 설명은 서술형이 아니라 근거 고르기로 |

그 밖에 코어 루프(30초/5분/한 판), "장마다 새 기믹 하나"(하야시다 기승전결), "실패해도 전진"(Hades), 탐정 게임 확인 장치(묶음 확인·근접 피드백), 방탈출 3단계 힌트를 썼다. 중세국어 게임에 특히 맞는 레퍼런스로 **Chants of Sennaar**(맥락으로 낯선 문자 해독)와 **Heaven's Vault**(기본 글자 합성 → 단어)가 이미 분석되어 있다.

## 3. 시리즈 공통 설계 원칙 27개 중 핵심 15개

| # | 원칙 | 중세국어 게임에서의 의미 |
|---|---|---|
| P1 | **학습 내용이 곧 메커닉**. 내용을 빼면 게임이 무너져야 한다 | 퀴즈를 덧붙이는 방식 금지 |
| P2 | **내용의 뼈대 = 핵심 동사의 모양** | 제자 원리 = 생성 체계(만들다), 문헌 = 해독(읽어 내다), 변화 = 변환(흘려보내다) |
| P3 | 모든 기획은 **"학생이 어려워하는 점 → 게임 장치" 표**로 시작한다 | 아래 03 문서 §1에 작성 |
| P4 | **가짜 원문은 만들지 않고, 원문은 한 글자도 바꾸지 않는다** | 언해본·용비어천가 원문은 출처 사슬과 테스트로 고정 |
| P5 | **사실·해석·허구 표지 체계** (原文 붉은 낙관 / 풀이 한지 / 게임 설정·虛 청록 / 이본 노트 황토 / 해석 쪽빛) | 그대로 계승 |
| P6 | **판정은 확실한 사실만**, 갈리는 것은 채점하지 않는다 | 예: ㆍ의 정확한 음가, 어두 자음군의 실제 발음 여부는 채점하지 않는다 |
| P7 | 판본 차이는 숨기지 말고 **'이본 노트'**로 | 해례본 vs 언해본, 두시언해 초간 vs 중간 |
| P9 | **사실 확인이 설계보다 먼저**, 실존 인물은 근거 있는 말만 | 세종의 말은 어제 서문에 근거한 것만 쓴다 |
| P12 | **AI 그림에 글자를 넣지 않는다 / 정확해야 하는 것은 코드로** | 옛글자·방점·발음 기관 단면도는 모두 SVG와 글꼴로 그린다 |
| P13 | 게임오버·타이머·반사신경 없음, 실패해도 전진 | 그대로 |
| P14 | 보상은 내용과 붙은 것만 (뽑기·경험치·랭킹 금지) | 보상 = 새 글자, 도감 칸, 완성한 문장 |
| P15 | **학생이 손으로 완성한 결과물 = 학습 요약** (캡처 제출) | 예: "내가 복원한 언해본 한 면", "나의 스물여덟 자 도감" |
| P22 | **"더하지 말고 빼라"** | 멋진 연결이라도 초점을 흐리면 뺀다 |
| P25 | **오개념 목록 → 게임 대응 표** | 03 문서 §2에 초안 |
| P27 | **소리와 문자를 섞지 않는다** (음운 해전 원칙) | 소리는 `/ㄱ/`, 글자는 〈ㄱ〉으로 표기를 나눈다 |

## 4. 개발 과정 (6개 게임에서 재구성한 표준 흐름)

```
[0] 기획안 v0 (선생님 초안 · 끝에 "이후 확정할 것" 체크박스)
      ↓  AI 리서치 (병렬)
[1] research/01_사실확인.md   +   research/02_게임설계_리서치.md
      ↓  인터뷰 (1~3차, 질문 | 결정 | 근거 표로 기록)
[2] 인터뷰 결정  (+ 화풍 시안 3~4종 → 선생님 선택)
      ↓
[3] 기획서/설계서 v1  (구현 기준. 끝에 "구현하면서 바뀐 점(날짜)"을 계속 덧붙임)
      ↓  구현
[4] 원문 검증 노트 (데이터 ↔ 원전, ✅⚠️❌, "현재 → 제안", 보고서만 쓰고 데이터는 고치지 않음)
[5] 학생 관점 검토 (학생 화면 대본 자동 생성 → 정답표 분리 → 성적대별 블라인드 풀이 에이전트 → 디자이너 검토)
[6] AI 플레이테스트·QA (실제 입력으로 완주, P0/P1/P2 보고서)
[7] 디자인 검수 (캡처만 보고, '높음' 지적이 0이 될 때까지)
[8] 선생님용 README (어려운 점↔장치 표, 차시 운영, 내용 고치기, 알려진 한계)
```

**누가 정하나**
| 선생님이 정함 | AI가 근거를 대고 고침 | AI가 묻고 보류 |
|---|---|---|
| 장르, 주인공, 범위, 차시, 화풍, 녹음 vs 합성, 교사 기능, 배포 | 사실 오류, 기준 판본 선택 근거 | 규칙·설명 방식을 바꾸는 제안 ("선생님께 여쭐 것") |

**이번 중세국어 게임의 현재 위치**: `[0]` 직전. 이 리서치 묶음(01·02·03)이 기획안 v0의 재료이고, 03 문서 끝의 "함께 정할 것"이 인터뷰 1차 질문이 된다.

## 5. 검토·검증 방법 (가장 효과가 컸던 것)

| 방법 | 출처 게임 | 핵심 | 성과 |
|---|---|---|---|
| **블라인드 풀이 에이전트** | 도산 | 학생 화면 대본만 주고 성적대별 페르소나(3~4등급 / 6~7등급)가 풀며 "어떻게 풀었나"(원문에 바로 나옴 / 보기 소거 / 추론 / 요령 / 찍음)를 기록 | "답이 이미 화면에 있음" 29→20, "보기 소거" 11→0 |
| 디자이너 역할 검토 | 도산 | 탭 수·글자 수·시간 측정 | 첫 게임다운 순간까지 9탭·1,140자(2.5~3.5분) 발견 |
| AI 실입력 플레이테스트 | 판소리·영웅 | 휴대폰 꼼꼼한 학생 / PC 서두르는 학생으로 완주 | 재접속 버그, 결과물-플레이 불일치(P0) 발견 |
| 균형 시뮬레이션 | 판소리 | 점수 함수를 전략별로 전수 계산 | 만능 구성·억지 선택 보너스 결함 발견 |
| 원문 기계 대조 | 관동·판소리 | `difflib` 글자 단위 대조, "원문 = 리서치 문서 글자" 테스트 | 99.6% 일치 확인, 오탈자 원천 차단 |
| 학생 검토(브라우저 에이전트) | 음운 해전 | "AI가 고칠 것 / 선생님이 결정할 것" 분리 | — |

**교훈 TOP 10 (중세국어 게임에 직결)**
1. **"답이 이미 화면에 있다"**가 가장 큰 문제였다. 풀이와 정답이 같은 말이면 글자 맞추기가 된다.
2. **원문 띄어쓰기가 함정**이 된다(도산 음보). 띄어쓰기 없는 15세기 원문을 다룰 때 특히 주의한다.
3. 오답 보기는 **오개념·기출 함정**에서 가져온다. 우스꽝스러운 오답은 안 읽고도 맞힌다.
4. 하위권 학생은 **옛한글 자체를 무서워한다** (풀이 에이전트 B: "ᅀ 이 세모 글자 어떻게 읽음? 무서움"). 첫 등장 때 읽는 법을 한 줄로 안내한다.
5. **옛한글 조합 표기가 화면에 날것으로 노출**되는 버그("[ㄹㆍㅁ]")가 있었다. 모든 표시 문자열에 변환기를 적용한다.
6. **절정 뒤에 퀴즈를 붙이지 않는다.**
7. 한 차시 읽기량은 18,000자를 넘으면 끝나지 않는다. **부분 제출**을 허용한다.
8. 분석 틀을 **보편 법칙으로 단정하지 않는다** ("모든 ~는" 대신 "많은 ~에서").
9. **AI 그림이 오개념을 만든다** (도산: 솔개 鳶을 종이연으로 그림). 그림도 오개념 기준으로 검수한다.
10. **한 게임 = 한 학습 초점.** 음운 해전에서 선생님이 훈민정음 연결을 통째로 뺀 이유다.

## 6. 에셋 제작 방법론 요약

### 6-1. 그림
| 단계 | 방법 |

**중세국어 게임 주의점**
- 화면 속 옛글자·언해본 지면·현판은 **모두 빈 종이로 그리고 글꼴로 얹는다** (생성 모델이 ㆍ·ㅿ를 틀리게 그림).
- **15세기 조선 전기 복식 문구를 새로 써야 한다.** 기존의 후기 조선 문구(갓·두루마기)를 그대로 쓰면 고증 오류.
- 화풍 후보: 15세기 판화 삽화(『삼강행실도』 계열 목판 삽화풍) 등. 영웅의 길이 방각본 목판을 이미 썼으므로 차이를 둔다.

### 6-3. 소리
- 국악 BGM: 국립국악원 「디지털 이음」 악구(**공공누리 제1유형**)를 이어 붙임. −17~−20 LUFS, 모노 64kbps. 출처는 게임 안·README·CREDITS 세 곳에 함께 적는다.
- 15세기 분위기 후보: 정악(「여민락」·「보허자」 등). 세종 시대와 연결되는 곡이라 맥락과도 맞는다. 받기 전에 선생님 확인을 거친다.
- **녹음 음성·TTS는 여섯 게임 모두 없다** (음운 해전 결정 0011: "학생이 직접 발음"). 중세국어 재구 발음을 들려줄지는 **새로 정해야 한다.**

## 8. 이 분석이 중세국어 게임에 주는 결론

1. **이 게임이 들어갈 자리는 이미 비어 있다.** 음운 해전 결정 0010에서 선생님은 "이 게임은 음운에 대한 이야기지 문자 제자 원리에 대한 게임은 아니"라며 훈민정음·해례·중세국어·제자 원리를 모두 뺐다. 새 게임은 그 **문자·제자 원리·중세국어** 쪽을 맡는다. 음운 해전과 역할이 겹치지 않는다.
2. **음운 해전에서 뺀 장면을 살릴 수 있다.** 기획안 v0의 "소리가 글자가 되는 순간"(단면도 속 혀 모양이 먹선으로 굳어 ㄱ이 되는 연출)과 "옛 바다"(해례 5음 분류) 단계, 그리고 4회 검수를 통과한 **입안 단면도 SVG**와 자질 데이터(`sounds.js`)는 바로 재사용할 수 있다.
3. **이미 있는 중세국어 데이터도 쓸 수 있다.** 도산십이곡의 1565년 목판본 판독(ᅀ, ᆞ, 구개음화 이전 '어디다', 어두 자음군 'ᄠᅦ')과 『청구영언』(1728) 대조표는 국어 변화 학습 자료로 그대로 쓸 수 있다.
4. **기술적 선결 과제는 두 가지다.** 방점이 깨지는 문제(글꼴 범위)와 옛한글 조합표 확장.
5. **반드시 정할 것이 하나 있다. 초점이다.** 시리즈의 교훈(한 게임 = 한 학습 초점)에 따라 "제자 원리(중학교)"·"표기와 문법(고1)"·"국어의 변화(고1~고2)" 가운데 초점을 고르거나, 편을 나눌지 정해야 한다. → 03 문서 §5에서 함께 정할 것.
