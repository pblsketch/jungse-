- 만든 날: 2026-10-01 · 도구: Codex `image_gen` (gpt-image-2), 1536×1024, quality high
- 네 장 모두 **같은 장면**이다. 1446년 한양 저잣거리에서 현대 교복을 입은 학생(정음 통사)이 해독 수첩을 들고, 방(榜)을 읽지 못하는 백성 옆에 서 있다. 중학 국어 2-2 136쪽 '창제 이전의 문자 생활' 장면에서 가져왔다.
- 그림 속 글자는 **알아볼 수 없는 붓 자국**으로만 그리게 했다. AI가 지어낸 옛한글이 화면에 나오지 않게 하려는 것이다(원칙 P4). 실제 게임에서 원문은 그림이 아니라 글꼴로 얹는다.
- 화면 위쪽 15%는 게임 UI 자리로 비워 두라고 지시했다.
