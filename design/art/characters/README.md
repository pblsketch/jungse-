## 고증 확인 (검증 필요)

- **선배 통사의 모자**: 15세기 조선 전기 갓은 후기 갓보다 대우(모자 꼭대기)가 둥글고 높으며, 챙이 지금 그림보다 좁았다고 알고 있다 **(검증 필요)**. 시대별 갓 모양 자료를 확인한 뒤 프롬프트를 고친다.
- **철릭**: 허리 아래 주름이 잡힌 형태로 그려졌다. 조선 전기 남성 포의 특징과 맞는지 확인 필요.
- **S2의 여성 행인**: 15세기 여성 저고리는 엉덩이까지 덮을 만큼 길었다 **(검증 필요)**. 견본의 짧은 저고리·앞치마 차림은 후기 모습에 가깝다.
- 01 문서 §6-1: "15세기 조선 전기 복식 문구를 새로 써야 한다. 후기 조선 문구(갓·두루마기)를 그대로 쓰면 고증 오류."

## 다음 단계

1. 복식 고증 자료를 확인하고 **15세기 복식 문구**(남·녀·관리·백성·승려)를 확정한다.
2. 주인공 4명 모두의 SD 걷기 시트를 만든다. 운동화 로고는 없앤다.
3. 스프라이트 제작 과정(칸 자르기, 크로마키, 정렬)은 「영웅의 길」 과정을 가져와 맞춘다.
