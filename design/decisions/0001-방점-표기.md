# 0001 방점 표기

- 날짜: 2026-10-01 · 상태: 채택 · 관련 코드: `js/core/yet.js`, `js/data/jamo.js`

## 결정

1. 데이터에서는 방점을 **음절 바로 앞**에 적는다. 거성(1점)은 가운뎃점 `·`(U+00B7), 상성(2점)은 쌍점 `:`. 예: `·나랏:[ㅁㆍㄹ]`.
   원문 판본에서 방점이 글자 왼쪽에 찍히는 모습과 같은 순서라 입력·검토가 쉽다.
2. 화면 출력은 유니코드 관례를 따라 **음절 뒤**에 U+302E `〮`(거성) / U+302F `〯`(상성)을 붙인다.
3. `·` `:` 는 바로 뒤가 음절(완성형 가–힣, 첫소리 자모로 시작하는 옛한글 음절, `[` 대괄호 음절)일 때만 방점이다.
   그 밖에는 글자 그대로다(`10:30`, `가 · 나`). 음절 앞에서 글자로 쓰려면 `\·` `\:`.
   따라서 "가·나"처럼 가운뎃점을 띄우지 않고 늘어놓으면 방점으로 읽힌다 — 나열에는 띄어 쓰거나 `\·` 를 쓴다.
4. 평성(점 없음)은 아무것도 적지 않는다. 데이터에 U+302E/302F 를 직접 적어도 된다(이미 음절 뒤 순서).
5. 방점 보이기/숨기기는 전역 설정 `NM.core.yet.setBangjeom(bool)` 과 호출별 `render(text, {bangjeom})` 로 바꾼다.
   숨기면 직접 적은 U+302E/302F 도 지운다. 화면 읽기용 `modernReading` 은 늘 방점을 뺀다.
6. 채점은 id 로 한다. 방점이 붙은 렌더 문자열을 정답 비교에 쓰지 않는다(화면 비교는 `same(a, b, {tone:false})`).

## 버린 안

- 음절 뒤에 적기(유니코드 순서 그대로): 원문 대조가 어렵고 `:` 가 문장부호와 섞인다.
- 숫자 표기(`가1`, `가2`): 데이터를 읽기 어렵다.

## 알려진 한계

- Noto CJK 바탕의 NMYet 은 방점을 음절 오른쪽의 좁은 점 글리프로 그린다(가로쓰기). 원문처럼 왼쪽에 찍히지는 않는다.
