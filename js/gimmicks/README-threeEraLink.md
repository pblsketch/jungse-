# 기믹 `threeEraLink` — 세 시대 변환 (스테이지 11 「끊어 적는 시대」)

spec §7 스테이지 11: **중세 → 근대 → 현대 어형 잇기**(셔ᄫᅳᆯ > 셔울 > 서울), **이어/거듭/끊어 적기 가르기**.
기믹 과제(spec §5-3)로 돈다. 판정·저장·도움 3단계는 장면 진행기가 하고, 이 기믹은 그리기·답 만들기·틀린 곳 표시만 한다.

- 코드 `js/gimmicks/threeEraLink.js` · 문구 `js/data/text-g-threeEraLink.js` · 모양 `css/g-threeEraLink.css`
- 두 부분이 있다. **하나만 써도 된다**(`chains` 만, 또는 `spell` 만). 둘 다 쓰면 한 창에 차례로 나온다.

## ① 세 시대 잇기 (`config.chains`)

줄마다 **중세 어형이 고정**되어 보이고, 아래에 섞인 조각(모든 줄의 근대·현대 어형 + `extra`)이 있다.
학생은 조각을 골라 그 줄의 **근대 칸·현대 칸**에 놓는다(조각 → 칸, 또는 칸 → 조각. 채운 칸을 다시 누르면 조각이 돌아간다).

- 판정은 **줄·칸마다 조각 id** 로 한다. 세기·연도는 판정하지 않는다(우리말샘 세기 범위가 겹친다 — 리서치 11 5절).
- 사슬은 리서치 11 5절 표에서 **확실도 ◎/○** 인 것만 쓴다. 칸은 **3칸**(중세·근대·현대)이다.
  - 셔ᄫᅳᆯ > 셔울 > 서울 (W-seoul) — `셔욿`은 `셔울`의 이형태다. 따로 한 칸으로 만들지 않는다(함정 6).
  - 둏다 > 죻다 > 좋다 (W-jota)
  - ᄆᆞᅀᆞᆷ > ᄆᆞᄋᆞᆷ > 마음 (W-maeum, 4단계 사슬에서 3칸만 고름. 근대 칸 `ᄆᆞᄋᆞᆷ`은 『중간노걸대언해』(1795) 原文에 나오는 꼴)
  - 근대 칸은 될 수 있으면 그 장면 原文(O-s11-NOGEOL1795: `셔울`·`죠흐료`·`ᄆᆞᄋᆞᆷ`)에 실제로 나오는 꼴로 고른다.
  - 2단계뿐인 사슬(믈 > 물, 디다 > 지다, 처음 등)은 이 부분에 넣지 않는다.
- `extra`(헷갈리게 하는 조각)는 **어느 줄에도 속하지 않는** 꼴만 넣는다. 다른 줄의 진짜 단계(예: `ᄆᆞ음`)를 넣으면 정답이 둘이 되므로 안 된다.

| 필드 | 뜻 |
|---|---|
| `chains` | `[{ id, forms: [중세, 근대, 현대] }]` — `forms` 는 데이터 표기(`셔[ㅸㅡㄹ]`). `id` 는 영문 |
| `extra` | 선택. 헷갈리게 하는 조각 `[데이터 표기]` |

**조각 id** 는 기믹이 만든다: 줄 `c` 의 근대 어형 = `'<c>.1'`, 현대 어형 = `'<c>.2'`, `extra[k]` = `'x.<k>'`.
그래서 정답은 늘 `link: { <c>: ['<c>.1', '<c>.2'] }` 꼴이다.

## ② 적는 방식 가르기 (`config.spell`)

原文 블록의 한 대목을 둘레 몇 낱말만 잘라 보이고, **밑줄 친 말**을 `이어 적기` / `거듭 적기` / `끊어 적기` 가운데 하나로 고른다.
原文 글자는 `NM.data.ORIG[블록 id]` 에서만 읽는다. 데이터에는 **찾을 말(`find`)만** 적는다(原文 줄을 옮겨 적지 않는다 — c3-orig 점검).

| 필드 | 뜻 |
|---|---|
| `spell.items` | `[{ id, orig, find, line?, nth?, radius? }]` |
| `id` | 대목 id(영문) |
| `orig` | 原文 블록 id (`O-s11-DOKRIP4`). 확실도 △ 블록(`O-s11-DONGMYEONG1`, `O-s11-AD1907`)은 쓸 수 없다 |
| `find` | 밑줄 칠 말. 그 줄의 데이터 표기 그대로(`[ㅎㆍㅁ]이라` 처럼 대괄호 포함). 대괄호·루비 경계에 맞아야 한다 |
| `line` | 블록의 몇째 줄(0부터, 기본 0) |
| `nth` | 같은 말이 여러 번 나오면 몇째(0부터, 기본 0) |
| `radius` | 앞뒤로 보일 낱말 수(띄어쓰기 단위, 기본 3). 잘린 쪽에는 `…` |
| `spell.kinds` | 선택. 보일 보기 `['ieo','geodeup','kkeuneo']` 의 부분 목록(기본 셋 다) |

확인된 사례(리서치 11 4-3절 '드러나는 항목'):
- O-s11-DOKRIP1 `거슨`(것+은) **이어 적기** ↔ `홈이라` **끊어 적기**
- O-s11-DOKRIP4 `아러보지` **이어 적기** ↔ `알아보니` **끊어 적기** — 한 문장 안에 함께 나온다(함정 9 "근대는 끊어 적기로 바뀌었다"의 반례)
- **거듭 적기**: 쓸 수 있는 原文 블록(◎/○)에는 확인된 사례가 없다(`같티`는 △ 블록 「동명일기」에만 있음). 그래서 보기로만 두고 정답으로는 쓰지 않는다. 선생님이 「동명일기」를 영인본과 대조해 ○로 올리면 그때 넣는다.

## 정답 (`answer`)

```js
{ link: { <줄 id>: [근대 칸 조각 id, 현대 칸 조각 id] }, spell: { <대목 id>: 'ieo' | 'geodeup' | 'kkeuneo' } }
```
정답에 있는 줄·대목만 판정한다(한 부분만 쓰면 그 키만 둔다).

## 도움 2단계 강조 (`hints[1]`)

줄 id(`'seoul'`), 대목 id(`'sp3'`), `'link'`(① 전체), `'spell'`(② 전체), 또는 그 배열. 그 부분에 ★ 와 점선 테두리가 붙는다.

## 틀린 부분 표시

틀린 제출 바로 뒤 틀린 **칸**과 틀린 **고름**에 ✕ 와 붉은 점선 테두리가 붙는다(색만으로 나누지 않음). 그 칸을 고치면 표시가 걷힌다.
3번째 틀림(또는 끝난 과제 다시 열기)에는 정답이 ○ 표시와 함께 채워지고 고칠 수 없게 된다.

## 원문 카드 (`config.orig`, 선택)

`orig: ['O-s11-NOGEOL1795']` 처럼 블록 id 를 주면 기믹 위에 原文 카드(낙관·제목·현대 표기 읽기)를 보인다.

## 전체 예시 (장면 데이터 `items` 안)

```js
{
  id: 's11.t1', kind: 'task', levels: ['h23'], label: '세 시대 변환', gimmick: 'threeEraLink',
  config: {
    orig: ['O-s11-NOGEOL1795'],
    chains: [
      { id: 'seoul', forms: ['셔[ㅸㅡㄹ]', '셔울', '서울'] },
      { id: 'jota',  forms: ['둏다', '죻다', '좋다'] },
      { id: 'maeum', forms: ['[ㅁㆍ][ㅿㆍㅁ]', '[ㅁㆍ][ㅇㆍㅁ]', '마음'] }
    ],
    extra: ['물'],
    spell: {
      items: [
        { id: 'sp1', orig: 'O-s11-DOKRIP1', find: '거슨' },
        { id: 'sp2', orig: 'O-s11-DOKRIP1', find: '홈이라' },
        { id: 'sp3', orig: 'O-s11-DOKRIP4', find: '아러보지' },
        { id: 'sp4', orig: 'O-s11-DOKRIP4', find: '알아보니' }
      ]
    }
  },
  answer: {
    link: { seoul: ['seoul.1', 'seoul.2'], jota: ['jota.1', 'jota.2'], maeum: ['maeum.1', 'maeum.2'] },
    spell: { sp1: 'ieo', sp2: 'kkeuneo', sp3: 'ieo', sp4: 'kkeuneo' }
  },
  hints: ['(1단계 힌트 — 장면 작성자가 새로 쓴다)', 'seoul'],
  explain: '(풀이 — 장면 작성자가 새로 쓴다)'
}
```

- 옛한글 음절(`셔ᄫᅳᆯ`·`ᄆᆞᅀᆞᆷ`…)을 장면 데이터에 새로 넣으면 글꼴 범위 점검(font-coverage)이 물결 끝 글꼴 재생성을 요구할 수 있다.
- 학교급별 용어 차이는 없다(스테이지 11은 고2~3 묶음). 보기 이름은 문구 파일에서 고친다.
