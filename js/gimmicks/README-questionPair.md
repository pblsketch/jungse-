# 기믹 `questionPair` — 질문 짝 맞추기 (장면 8 「묻는 말」, 고2~3)

물음(原文 블록)마다 학생이 세 가지를 고르고 한 번에 제출한다.

1. **짝이 되는 대답** — `config.answers` 가 있을 때만 나온다.
2. **어떤 물음인가** — 판정 의문(`yesno`) / 설명 의문(`wh`) / 2인칭 주어 의문(`second`).
3. **물음을 끝맺는 어미** — 기본 카드 `-가`(`ga`) · `-고`(`go`) · `-ㄴ다`(`nda`). `config.endings` 로 바꿀 수 있다.

판정은 진행기가 하고(이 기믹의 `check`), 도움 단계는 spec §5-3 그대로다.

- 틀린 제출: 틀린 고르기 묶음에 `✕` 와 점선 테두리(`is-wrong`)가 바로 붙는다. 상태는 `open`.
- 2번째 틀림: 진행기가 `showHint(2, hints[1])` 를 부른다. `hints[1]` 이 물음 id 면 그 물음의, 아니면 방금 틀린 물음들의
  **단서 낱말**(`cue` — 의문사·2인칭 주어)과 **어미 낱말**(`ending`)을 빛내고 `◆ 의문사` / `◆ 2인칭 주어` / `◆ 의문사 없음` 이름표를 단다.
- 3번째 틀림: `doneByHelp`. 정답 칸에 `○` 와 '정답' 이름표, 모두 잠금. 다시 열어도 같은 모습(읽기 전용).

용어 근거: 화법과 언어 205쪽 표(판정 의문 -가, 설명 의문 -고, 2인칭 주어 -ㄴ다). 의문 체계는 공통국어2에 없다(05 문서) — 고2~3 묶음 전용.
화면 문구는 `js/data/text-g-questionPair.js`(학교급별 덮기 `levels.<학교급>`).

## `config`

| 필드 | 필수 | 뜻 |
|---|---|---|
| `questions` | ○ | 물음 목록(아래) |
| `answers` | | 대답 카드 `[{ id, orig?, text?, who? }]`. `orig` 는 原文 블록 id(하나 또는 배열), `text` 는 장면 작가가 **새로 쓴** 말(데이터 표기). 비우면 짝 맞추기 단계가 없다 |
| `endings` | | 어미 카드 `[{ id, text }]`(데이터 표기, 예: `'-[ㆁㅣㅅ]가'`). 없으면 기본 세 장(`ga`·`go`·`nda`) |

물음 하나:

| 필드 | 필수 | 뜻 |
|---|---|---|
| `id` | ○ | 이 과제 안에서만 쓰는 id(`q1` …) |
| `orig` | ○ | 原文 블록 id 또는 배열. 주어가 앞 구절에 있으면 앞 구절 블록을 먼저 둔다(예: `['O-s6-SS6e', 'O-s8-SS6f']`) |
| `words` | | 原文 안에서 빛낼 낱말 `[{ id, block?, line?, match? \| at?, nth? }]` — 아래 '낱말 지정' |
| `cue` | | 단서 낱말 id 목록(의문사, 2인칭 주어). 판정 의문이면 비운다 |
| `cueKind` | | `'wh'`(의문사) · `'second'`(2인칭 주어) · `'none'`(의문사 없음). 없으면 `cue` 가 비었을 때 `'none'` |
| `ending` | | 어미가 든 낱말 id 목록(2번째 틀림·정답 때 겹밑줄) |
| `who`, `lead` | | 묻는 사람 이름, 앞 맥락 한 줄(데이터 표기, 장면 작가가 새로 씀) |

### 낱말 지정 (G7·G8·G9 공통, `js/gimmicks/g789-origwords.js`)

原文 글자는 config 에 옮겨 적지 않는다. 낱말은 **原文 줄 안의 자리**로만 가리킨다.

- `match`: 그 줄의 데이터 표기 조각열 그대로(방점까지). 예: `':엇·뎨'`, `'듣[ㄴㆍㄴ]·다'`. 조각 경계에 맞아야 한다
  (조각 = `[…]` 한 음절 · `{漢|읽기}` 루비 하나 · 음절/한자/홑 자모 한 글자, 방점은 뒤 음절에 붙음). 같은 꼴이 여럿이면 `nth`(1부터).
- `at: [시작, 개수]`: 조각 자리(0부터, 빈칸은 세지 않음)로 가리킨다.
- `block`: 물음의 `orig` 가 여럿일 때 어느 블록인지. `line`: 블록의 몇째 줄(기본 0).
- 못 찾거나 겹치면 `NM.reportError('g789.word', …)` 로 알린다(점검 실패). 줄 전체(6자 이상)를 `match` 에 넣지 않는다 — c3-orig 가 '옮겨 적음'으로 본다.

## `answer`

```js
{ <물음 id>: { pair?: <대답 id>, kind: 'yesno' | 'wh' | 'second', ending: <어미 id> } }
```

`check` 는 `answer` 에 적힌 칸만 본다(대답 카드가 없으면 `pair` 를 적지 않는다). 틀린 칸은 `{ wrong: { q1: ['kind'] } }` 로 `showWrong` 에 간다.

## 예 (장면 8 고2~3 — 블록·드러나는 항목은 10 문서 §4·§5)

```js
{
  id: 's8.t1', kind: 'task', levels: ['h23'], label: '질문 짝 맞추기', gimmick: 'questionPair',
  prompt: '스님과 羅雲이 주고받은 말을 통역하기 전에, 물음마다 짝과 갈래를 가려 보자.',
  config: {
    questions: [
      // 2인칭 주어 -ㄴ다: 주어 ':네'는 바로 앞 구절(O-s6-SS6e)에 있다
      { id: 'q1', orig: ['O-s6-SS6e', 'O-s8-SS6f'],
        words: [{ id: 'q1.you', block: 'O-s6-SS6e', match: ':네' }, { id: 'q1.end', block: 'O-s8-SS6f', match: '듣[ㄴㆍㄴ]·다' }],
        cue: ['q1.you'], cueKind: 'second', ending: ['q1.end'] },
      // 설명 의문 -고: 의문사 '어·듸'
      { id: 'q2', orig: 'O-s8-YB47',
        words: [{ id: 'q2.wh', match: '어·듸' }, { id: 'q2.end', match: '[ㅎㆍ]·리[ㆁㅣㅅ]·고' }],
        cue: ['q2.wh'], cueKind: 'wh', ending: ['q2.end'] },
      // 판정 의문 -가: 의문사 없음(쓰임은 반어 — 형식만 판정, 10 문서 §8)
      { id: 'q3', orig: 'O-s8-YB15',
        words: [{ id: 'q3.end', match: '·[ㅳㅡ]디·리[ㆁㅣㅅ]·가' }],
        cue: [], cueKind: 'none', ending: ['q3.end'] }
    ],
    answers: [
      { id: 'a1', orig: 'O-s8-SS6g', who: '羅雲' },      // 『석보상절』 권6 11ㄱ, SS6f 바로 다음 구절(실제 대답)
      { id: 'a2', text: '(장면 작가가 새로 쓴 대답)' },
      { id: 'a3', text: '(장면 작가가 새로 쓴 대답)' }
    ]
  },
  answer: {
    q1: { pair: 'a1', kind: 'second', ending: 'nda' },
    q2: { pair: 'a2', kind: 'wh', ending: 'go' },
    q3: { pair: 'a3', kind: 'yesno', ending: 'ga' }
  },
  hints: ['의문사가 있는지, 주어가 듣는 사람인지부터 보자.', 'q2'],
  explain: '(장면 작가가 새로 쓴 풀이 — 교과서·번역서 문장을 옮기지 않는다)'
}
```

## 장면 작가가 지킬 것

- 原文은 블록 id 로만. 쓸 수 있는 s8 블록: `O-s8-SS6f`·`SS6g`·`SS6i`·`SS68`·`WS894`·`YB15`·`YB88`·`YB28`·`YB47` (+ 주어가 든 `O-s6-SS6e`).
- **판정 의문**은 `YB15`(-리ᅌᅵᆺ가)·`YB88`(-더신가)로 채운다. 체언 바로 뒤 '가'(`WS894` '죵가')는 15세기 구절이 하나뿐이고
  방점을 판독하지 못한 블록이다(10 문서 §0) — 쓰더라도 짝 맞추기의 대답 카드나 알아 두기로만.
- `SS6i` 의 '네'는 평성(관형격)으로 판독했고 판독이 약하다(10 문서 §8) — 2인칭 주어 단서(`cue`)로 쓰지 않는다. `SS6f`·`SS68` 을 먼저 쓴다.
- 대답 카드의 `text`, `lead`, `explain` 은 새로 쓴다(번역서·시험 지문 문장 금지).
- `NM.data.RULE_CARDS` 는 쓰지 않는다(규칙 카드 확정은 해독 항목의 `ruleCard` 몫).
