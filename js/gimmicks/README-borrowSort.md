# 기믹 `borrowSort` — 스테이지 1 「빌려 쓴 글자」 뜻이냐 소리냐

原文 줄의 한자마다 **그 글자의 뜻을 빌렸는지(훈차) 소리를 빌렸는지(음차)** 고른다.
사례를 다 가르면 규칙 카드 문장 완성 공용 부품(`o.rulecard`, `js/ui/rulecard.js`)이 열려 규칙
"실질 형태소는 대체로 뜻, 조사·어미는 대체로 소리"를 확정한다(spec §7 스테이지 1, 고2~3).

- 파일: `js/gimmicks/borrowSort.js`, 문구 `js/data/text-g-borrowSort.js`, 모양 `css/g-borrowSort.css`
- 原文 글자는 `NM.data.ORIG` 에서만 그린다. config 는 **블록 id 와 글자 자리**만 적는다(옮겨 적지 않는다).
- 판정은 표시 id 와 카드 id 로 한다. 틀린 한자는 ×·점선, 규칙 칸도 ×, 2단계 강조는 △, 정답은 ○.

## `config`

| 필드 | 필수 | 뜻 |
|---|---|---|
| `lines` | ○ | 원문 줄 목록(아래) |
| `rule` | | `{ sentence, cards: [{ id, text }] }` — 규칙 문장(빈칸 `{?}` 하나)과 카드. 없으면 가르기만 한다 |
| `labels` | | `{ hun, eum }` 단추 글자 바꾸기(기본 '뜻' / '소리') |

`lines` 의 한 줄:

| 필드 | 뜻 |
|---|---|
| `orig` | 原文 블록 id(`O-s1-…`) |
| `line` | 그 블록 `lines` 의 몇째 줄(0부터) |
| `targets` | 고를 한자 `[{ at, id, note? }]`. `at` = 줄 안 글자 자리(0부터, **빈칸도 한 자리**). `id` = 표시 id(과제 안에서 겹치지 않게) |
| `targets[].note` | `{ kind: 'know' \| 'interp', text }` — 끝난 뒤(맞음·정답 보기)에만 그 줄 아래에 보이는 설명 |
| `notes` | 고르지 않는 글자 설명 `[{ at: 자리 또는 [자리…], kind: 'interp' \| 'know', text }]`. 처음부터 보이고 그 글자는 물결 밑줄. **고르는 글자에는 달 수 없다** |

줄은 대괄호·루비 표기가 없는 한자 줄이어야 한다(S1 블록은 모두 그렇다).

## `answer`

`{ marks: { <표시 id>: 'hun' | 'eum' }, rule?: '<맞는 카드 id>' }` — `hun` = 뜻을 빌림, `eum` = 소리를 빌림. `config.rule` 이 있으면 `rule` 도 적는다.

## `hints`

`[1단계 힌트, 2단계 강조 대상]` — 강조 대상은 표시 id, `'rule'`, 또는 그 배열. `null` 이면 마지막에 틀린 곳.

## 무엇을 채점하나 (리서치 11 문서 'S1 판정표'·9절·11절)

| 블록 · 자리 | 글자 | 판정 | 처리 |
|---|---|---|---|
| `O-s1-YEONGDONG` 0줄 `at 0` / `at 5` | 永 / 吉 | 뜻 / 소리 | 채점 |
| `O-s1-SEODONG1` 0줄 `at 4` / `at 5` | 主(님) / 隱(은) | 뜻 / 소리 | 채점. 앞의 善化公主 는 판정표에 없으므로 고르지 않는다 |
| `O-s1-CHEOYONG1` 1줄 `at 0~6` | 夜 入 伊 遊 行 如 可 | 뜻 뜻 소리 뜻 뜻 **뜻** 소리 | 채점. 如 는 어미 자리지만 새김을 빌린 훈가자 → `note`(알아 두기) 필수 |
| `O-s1-CHEOYONG1` 0줄 `at 0,1` / `at 5` | 東京 / 良 | 학설 갈림 | `notes`(해석), 채점 안 함 |
| `O-s1-CHEOYONG1` 0줄 明·期·月 | | 교과서 밖 | 탐색 보충(맥락 대사·알아 두기). 이 기믹으로 채점하지 않는다 |
| `O-s1-MILSEONG` (推 뜻 / 密 소리) | | 교과서 밖 반례 | "옛 이름은 늘 소리" 오개념을 깨는 탐색 보충 |
| `O-s1-SUSEONG` (買·忽 / 水·城) | | 교과서 밖 | 고2~3 알아 두기 |
| `O-s1-SEODONG2` | | ○ 블록, 卯 판독 갈림 | 쓰려면 乙·矣·夜 처럼 합의된 글자만, 卯乙 은 해석 |

규칙 문장은 "언제나"가 아니라 **"대체로"** 다(如 가 예외). 카드에 함정 "조사·어미는 언제나 소리" 를 오답으로 넣으면 좋다.

> 표기 주의: 장면 데이터에서 가운뎃점을 음절 바로 앞에 붙이면 방점이 된다. `조사·어미` 는 '어'에 점이 찍히므로 `조사와 어미` 또는 `조사 · 어미` 로 적는다.

```js
{
  id: 's1.t1', kind: 'task', levels: ['h23'], label: '뜻이냐 소리냐',
  prompt: '비석과 노래의 한자마다 뜻을 빌렸는지 소리를 빌렸는지 가려 보자.',
  gimmick: 'borrowSort',
  config: {
    lines: [
      { orig: 'O-s1-YEONGDONG', line: 0, targets: [{ at: 0, id: 'yeong' }, { at: 5, id: 'gil' }] },
      { orig: 'O-s1-SEODONG1', line: 0, targets: [{ at: 4, id: 'ju' }, { at: 5, id: 'eun' }] },
      { orig: 'O-s1-CHEOYONG1', line: 0, targets: [], notes: [
        { at: [0, 1], kind: 'interp', text: '東京 을 한자어 그대로 읽는 풀이와 우리말 이름으로 읽는 풀이가 함께 있다.' },
        { at: 5, kind: 'interp', text: '良 은 소리를 빌렸다는 풀이와 새김을 빌렸다는 풀이가 갈린다.' }
      ] },
      { orig: 'O-s1-CHEOYONG1', line: 1, targets: [
        { at: 0, id: 'ya' }, { at: 1, id: 'ip' }, { at: 2, id: 'i' }, { at: 3, id: 'yu' }, { at: 4, id: 'haeng' },
        { at: 5, id: 'yeo', note: { kind: 'know', text: '如 는 어미 -다가 의 다 를 적었지만, 글자의 소리가 아니라 새김에서 다 를 빌렸다(훈가자). 그래서 규칙은 언제나가 아니라 대체로다.' } },
        { at: 6, id: 'ga' }
      ] }
    ],
    rule: {
      sentence: '실질 형태소는 대체로 뜻을, 조사와 어미는 {?} 빌려 적었다.',
      cards: [
        { id: 's1.t1.a', text: '대체로 소리를' },
        { id: 's1.t1.b', text: '언제나 소리만' },
        { id: 's1.t1.c', text: '대체로 뜻을' }
      ]
    }
  },
  answer: {
    marks: { yeong: 'hun', gil: 'eum', ju: 'hun', eun: 'eum', ya: 'hun', ip: 'hun', i: 'eum', yu: 'hun', haeng: 'hun', yeo: 'hun', ga: 'eum' },
    rule: 's1.t1.a'
  },
  hints: ['낱말의 뜻을 맡은 글자와 조사나 어미 자리에 붙은 글자를 나누어 봐.', 'rule'],
  explain: '永 은 뜻 길- 을, 吉 은 소리 길 을 빌려 같은 고장을 적었다. 향찰에서도 夜 入 遊 行 처럼 뜻을 가진 말은 뜻을, 伊 可 隱 처럼 조사와 어미는 소리를 빌렸다. 다만 如 처럼 어미를 새김으로 적은 예외가 있어 대체로라고 한다.'
}
```

## 알아 둘 것

- 규칙 카드를 수첩에 붙이는 일: 지금 진행기는 **해독 항목(`kind:'read'`)의 `ruleCard`** 만 수첩에 붙인다. 이 과제에서 확정한 규칙을
  수첩에 남기려면 같은 장면에 `ruleCard` 가 있는 규칙 해독 항목을 따로 두거나, 진행기가 과제의 `ruleCard` 도 받도록 바꿔야 한다(G2 보고의 걱정거리).
