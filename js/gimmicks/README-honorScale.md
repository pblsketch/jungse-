# 기믹 `honorScale` — 높임 저울 (s7 「높이는 말」, 고2~3)

누가 누구를 높이는지 고른 뒤 선어말 어미 활자를 골라 빈 활자 자리에 끼우는 기믹 과제다(spec §7 s7, plan G6).

- 활자 자리(slot)마다 **조판**을 보인다: 原文 줄(블록 id)을 그대로 다시 짜되, 선어말 어미가 든 글자 범위만 빈 활자 자리로 비운다.
  같은 줄의 다른 활자 자리도 끝나기 전에는 비워 둔다(…). 과제가 끝나면(맞힘·3번째 틀림·다시 열기) 조판을 **原文대로** 되돌려
  끼운 자리를 ◎ 테두리로 보이고, 原文 카드(낙관·출처)를 함께 보인다. 原文 글자는 바꾸지 않는다.
- ① **인물 패**: 이 자리의 말이 높이는 사람을 고른다. 패마다 자리 이름(주체·객체·상대)과 인물 이름, 짧은 설명이 있다.
  **화자** 패는 저울 왼쪽에 놓여 있다(고르지 않음).
- ② **활자**: 인물 패를 고른 뒤에야 고를 수 있다. 활자를 끼우면 저울의 화자 쪽에 활자 추가 얹혀 높임 받는 사람 쪽이 올라간다
  (움직임 줄이기면 전환 없이 바로 기운 모양). 빈 자리를 누르면 활자가 빠진다. 키보드: Tab·Enter·Space.
- 판정은 id 로 한다: 자리마다 `honored`(높임 받는 자리)와 `ending`(활자 id)이 정답과 같아야 맞음.
- 틀린 제출: 틀린 인물 패·틀린 활자(빈 자리와 쟁반의 그 활자)가 흐려진다(✕, 점선). 도움 2(`hints[1]`): 활자가 틀렸으면 빈 자리·쟁반과
  **단서 글자**(기본: 빈 자리 바로 앞 글자, `cue` 로 바꿈)를 `!` 로, 인물이 틀렸으면 인물 패 묶음을 강조.

## 활자 목록 (`js/data/text-g-honorScale.js` 의 `endings`)

| id | 활자(데이터 표기) | 높이는 자리 |
|---|---|---|
| `si` | `-시-` | 주체(subject) |
| `sya` | `-샤-` | 주체(subject) |
| `sab` | `-[ㅅㆍㅂ]-` | 객체(object) |
| `jab` | `-[ㅈㆍㅂ]-` | 객체(object) |
| `zab` | `-[ㅿㆍㅂ]-` | 객체(object) |
| `ii` | `-[ㆁㅣ]-` | 상대(listener) |

분류 근거: spec §7 s7, 10 문서 §10 오개념 10~12(화법과 언어 205쪽 표). 객체 높임 세 활자가 **앞소리에 따라 갈리는 조건은
리서치 문서(02·05·09·10)에서 확인하지 못해** 기믹·문구에 넣지 않았다(02 문서도 '앞소리에 따라 형태가 바뀜 (검증 필요)'로만 적음).
장면 작성자는 화법과 언어 205쪽으로 조건을 확인한 뒤 `explain`·힌트를 새로 쓴다. 기믹은 단서 글자만 강조한다.

## 항목 데이터

```js
{
  id: 's7.t1', kind: 'task', levels: ['h23'], label: '…', prompt: '…',
  gimmick: 'honorScale',
  config: {
    cast: {                                    // 인물 id → { name(데이터 표기) }
      writer: { name: '…' }, buddha: { name: '부처' }, rahula: { name: '{羅|라}{雲|운}' }
    },
    choices: ['si', 'sya', 'sab', 'jab', 'zab', 'ii'],   // (선택) 쟁반 활자와 순서. 자리마다 choices 로 바꿀 수 있다
    slots: [
      { id: 'a', block: 'O-s7-SS6b', word: [4, 8], slot: [6, 7],
        roles: { speaker: 'writer', subject: 'buddha' } },
      { id: 'b', block: 'O-s7-SS6b', word: [8, 12], slot: [10, 11],
        roles: { speaker: 'writer', subject: 'rahula', object: 'buddha' } }
    ]
  },
  answer: {                                    // 자리 id → { honored: 'subject'|'object'|'listener', ending: 활자 id }
    a: { honored: 'subject', ending: 'sya' },  // 니[ㄹㆍ]·샤·도 — 주체 높임, 높이는 대상 부처
    b: { honored: 'object', ending: 'zab' }    // {從}·[ㅎㆍ][ㅿㆍㅂ]·디 — 객체 높임, 높이는 대상 부처(주어는 羅雲)
  },
  hints: ['…선배의 힌트…', { b: ['ending'] }], // 2단계 강조: 자리 id → 'honored' | 'ending' (또는 배열)
  explain: '…풀이(어미가 뒤 어미와 녹아 붙은 꼴 설명 등, 교과서로 확인해 새로 씀)…'
}
```

| 필드 | 뜻 |
|---|---|
| `slots[].block` (`line`) | 原文 블록 id(여러 줄이면 줄 번호). 原文 글자는 config 에 쓰지 않는다 |
| 글자 번호 | 그 줄에서 **빈칸을 빼고 0부터** 센 순서. 루비 `{漢\|음}` 하나 = 한 글자. 범위 `[시작, 끝]` 은 끝을 포함하지 않는다 |
| `word` | 밑줄로 보일 낱말(어절) 범위 |
| `slot` | 비울 글자 범위 = 선어말 어미가 든 음절들. 어미가 뒤 어미와 녹아 붙었으면 그 음절째 비운다(예: `請·[ㅎㆍ][ㅿㆍ]·[ㅸㅏ]` 는 13–15) |
| `cue` | (선택) 도움 2에서 강조할 단서 글자 범위. 생략하면 `[slot[0]-1, slot[0]]`(빈 자리 바로 앞 글자) |
| `roles` | `{ speaker?, subject?, object?, listener? }` — 인물 id. 적은 자리만 인물 패가 된다(speaker 는 저울 왼쪽, 고르지 않음) |
| `answer` | `{ 자리 id: { honored, ending } }` |
