# 기믹 `wordCut` — 끊어 읽기 (s4 「소리대로 적은 책」)

띄어쓰기 없이 찍힌 原文 줄을 낱말 경계로 끊는 기믹 과제다(spec §7 s4, plan G5).

- 原文 줄을 글자(음절·한자·루비 `{漢|음}` 하나)마다 단추로 늘어놓는다. **빈칸은 보이지 않는다**(원본에는 띄어쓰기가 없다).
- 글자를 누르면 **그 글자 뒤**가 끊긴다. 다시 누르면 끊은 자리가 없어진다. 마지막 글자는 끊을 수 없다. 키보드: Tab 으로 글자, Enter·Space 로 끊기.
- **방점 음높이 막대**(기본 켬): 글자 아래에 평성 = 낮은 가로 막대, 거성 = 높은 가로 막대, 상성 = 오르는 비탈 막대. 한자(독음 없음)는 막대가 없다.
  막대 설명에는 '해석' 표지와 "막대는 어림" 문구가 붙는다(정확한 높낮이 값은 학설이 갈림 — 10 문서 §8, 채점 안 함). s4·s10 은 진행기가 방점을 늘 켠다.
- **두 장 견주기**(선택): 두 줄의 같은 말(또는 맞대 볼 말)을 나란히 보인다. 학생의 끊기가 그 말을 딱 떼어 내면 '끊어 찾음'으로 바뀐다(판정과 상관없음).
- 틀린 제출: 정답에 없는 끊기 자리가 **번진다**(붉은 번짐 + ✕). 끊어야 하는데 안 끊은 자리가 든 말은 물결 밑줄. 도움 2: `hints[1]` 의 자리를 ▼ 로 강조(없으면 지난 틀린 자리 전부).
  3번째 틀림·다시 열기: 정답 끊기를 ◎ 로 보이고 잠근다. 문구는 `js/data/text-g-wordCut.js`.

## 항목 데이터

```js
{
  id: 's4.t1', kind: 'task', levels: ['h1', 'h23'], label: '…', prompt: '…',
  gimmick: 'wordCut',
  config: {
    lines: [ { block: 'O-s4-YB2a' }, { block: 'O-s4-YB34a' } ],   // 끊을 原文 줄(블록 id, 여러 줄 블록이면 line: 번호)
    pitch: true,                                                   // 방점 음높이 막대(생략하면 켬, false 면 끔)
    compare: [                                                     // 두 장 견주기(선택)
      { a: { block: 'O-s4-YB2a', at: [2, 4] }, b: { block: 'O-s4-YB34a', at: [1, 3] }, note: '…새로 쓴 짧은 설명…' }
    ]
  },
  answer: {                                                        // 줄 열쇠 → 끊는 글자 번호(그 글자 '뒤'를 끊음), 줄마다 빠짐없이
    'O-s4-YB2a': [1, 3, 5, 8, 10, 12, 13, 15, 17],
    'O-s4-YB34a': [0, 2, 3, 7, 10, 14, 15, 16, 18]
  },
  hints: ['…선배의 힌트…', { 'O-s4-YB2a': [1, 3] }],             // 2단계 강조: 줄 열쇠 → 강조할 끊기 자리
  explain: '…풀이…'
}
```

| 필드 | 뜻 |
|---|---|
| `config.lines[]` | `{ block, line? }`. `block` 은 `NM.data.ORIG` 블록 id. 原文 글자는 config 에 쓰지 않는다 |
| 줄 열쇠 | `block`(첫 줄) 또는 `block#line`(둘째 줄부터, 예: `'O-x-Y#1'`) |
| 글자 번호 | 그 줄에서 **빈칸을 빼고 0부터** 센 순서. 방점은 앞 글자에 붙지 않고 뒤 음절의 일부다. 루비 `{漢\|음}` 하나 = 한 글자, 독음 없는 한자 하나 = 한 글자 |
| `config.compare[]` | `{ a: {block, line?, at:[시작, 끝]}, b: {…}, note? }`. `at` 은 글자 번호 범위(끝은 포함하지 않음). `note` 는 데이터 표기 문장(새로 씀) |
| `answer` | 줄 열쇠 → 끊는 글자 번호 배열(순서 무관). 판정은 줄마다 집합이 같아야 맞음 |
| `hints[1]` | `{ 줄 열쇠: [글자 번호…] }` — 2번째 틀림에 그 자리를 강조. 생략하면 지난 제출의 틀린 자리 |

학교급: 고1·고2~3 같은 과제를 쓴다. **고2~3 모음 조화**는 `levels: ['h23']` 인 과제(또는 해독 항목)를 따로 두어 추가한다
(예: `O-s4-YB2b` 를 끊고 `·므·른`(4–6) ↔ `·[ㄱㆍ][ㅁㆍ]·래`(6–9) 를 견주기 — 10 문서 §5 's4 (고2~3) 모음 조화').

## 블록별 정답 경계 (장면 작성자가 정함 — 기준: 10 문서 §1)

10 문서 §1: "원본에는 띄어쓰기가 없다. 블록의 빈칸은 통용 띄어쓰기(위키문헌·교과서 풀이 기준)이고 **s4 끊어 읽기의 정답 경계로 쓴다**."

견주기 후보(10 문서 §4 '드러나는 항목'·§5 표에서 고름 — 범위는 위 번호):

| 견줄 말 | a | b | 드러나는 것 |
|---|---|---|---|
| `기·픈` ↔ `깊·고` | YB2a `[2, 4]` | YB34a `[1, 3]` | 같은 '깊-': 이어 적기(깊+은) / 8종성법 예외(받침 ㅍ 그대로) |
| `깊·고` ↔ `높·고` | YB34a `[1, 3]` | YB34b `[1, 3]` | 8종성법 예외 두 곳(공통국어2 135쪽 '깊고·높고') |
| `:업·건마·[ㄹㆍㄴ]` | YB34a `[4, 8]` | YB34b `[5, 9]` | 제34장 앞절·뒷절의 같은 말 |
| `하·[ㄴㆍㄹ]·히` | YB34a `[8, 11]` | YB34b `[9, 12]` | ㅎ 종성 체언 + 주격 '이'(같은 말 반복) |
| (고2~3) `·므·른` ↔ `·[ㄱㆍ][ㅁㆍ]·래` | YB2b `[4, 6]` | YB2b `[6, 9]` | 모음 조화(은 / 애) |

견주기 `note` 와 `explain` 은 장면 작성자가 교과서 문장을 옮기지 않고 새로 쓴다.
