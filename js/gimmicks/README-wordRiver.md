# 기믹 `wordRiver` — 변화의 강 (종장 「말의 강」 고등판)

spec §7 종장 고등판: **변화의 강** — 낱말이 강을 따라 흘러 바뀌는 순서 놓기(**순서만 판정, 연도 채점 안 함**), **지금 일어나는 변화 찾기**, **500년 뒤 예측 한 줄(채점 안 함)**.
기믹 과제(spec §5-3)로 돈다. 판정·저장·도움 3단계는 장면 진행기가 하고, 이 기믹은 그리기·답 만들기·틀린 곳 표시만 한다.

- 코드 `js/gimmicks/wordRiver.js` · 문구 `js/data/text-g-wordRiver.js` · 모양 `css/g-wordRiver.css`
- 세 부분: ① 변화의 강(`words`, 필수) ② 지금의 변화(`now`, 선택) ③ 500년 뒤 한 줄(`predict`, 선택)

## 중학교판은 이 기믹을 쓰지 않는다 (결정)

spec §7: 종장 **중학교판의 핵심 항목은 해독 항목 3개**(한·중·일 입력 방식 비교, 'ㅏ'와 'a' 음성 인식, 모아쓰기와 풀어쓰기)이고,
**두 관점 성찰 한 줄(줄임말)은 채점하지 않는 돌아보기**다. 그래서
- 중학교판은 장면 파일의 `editions.m` 에 해독 항목(카드 + 맥락 2곳)만 둔다 — 장면 진행기가 돌린다.
- 줄임말 두 관점(편리함 / 소통 어려움)은 맥락 대사나 알아 두기로 **새로 쓴 한 줄씩** 보이고, 성찰 한 줄은 장면 끝 '돌아보기 한 줄'(진행기, 기록에 남음)이 받는다.
- 중학교판에 따로 기믹 모드를 두지 않았다(최소 구현). EBS 영상의 입력 시간 수치(6초·9초·14초, 7~8배)는 리서치 11에서 △ — 쓰지 않는다.

## ① 변화의 강 (`config.words`)

낱말마다 강을 따라 **나루**(앞 → 뒤)가 단계 수만큼 있고, 아래에 그 낱말의 꼴들이 섞여 있다.
조각을 누르면 **다음 빈 나루**에 놓이고, 놓인 조각을 누르면 돌아온다. 화면에 연도·세기는 나오지 않는다.

| 필드 | 뜻 |
|---|---|
| `words` | `[{ id, label?, forms: [앞 → 뒤 차례로] }]` — `forms` 는 데이터 표기(`조[ㅄㆍㄹ]`), 2개 이상 |
| `label` | 선택. 낱말 이름(지금 꼴, 예 `'좁쌀'`). 없으면 'n번째 낱말' |

**조각 id** 는 기믹이 만든다: 낱말 `w` 의 `forms[k]` = `'<w>.<k>'`. `forms` 를 **바른 차례로** 적으므로 정답은 늘 `['<w>.0', '<w>.1', …]` 이다.

쓸 수 있는 사슬(리서치 11 5절, 우리말샘 역사 정보·표준국어대사전 어원으로 **순서** 확정, 공통국어2 138쪽 낱말):

| 낱말 | `forms` (데이터 표기) | 확실도 |
|---|---|---|
| 안팎 | `['안[ㅍㅏㅺ]', '안팎']` | ◎ |
| 좁쌀 | `['조[ㅄㆍㄹ]', '좁[ㅄㆍㄹ]', '좁[ㅆㆍㄹ]', '좁쌀']` | ◎ |
| 숟가락 | `['술', '숫가락', '숟가락']` | ◎ |
| 살코기 | `['[ㅅㆍㄹ]고기', '살코기']` | ○ — 세기별 역사 정보가 없어 **두 칸만** |

- 세기 범위는 겹친다(예: 조ᄡᆞᆯ 15~19 / 좁ᄡᆞᆯ 16~18). 세기는 '알아 두기'(장면 `notes`)로만 보이고 판정하지 않는다.
- 살코기의 'ㅎ 끝소리(ᄉᆞᆶ) + 고기 → 코기' 설명은 알아 두기로 둔다(판정 안 함).

## ② 지금의 변화 찾기 (`config.now`, 선택)

| 필드 | 뜻 |
|---|---|
| `now.choices` | `[{ id, text }]` — 보기(데이터 표기 문장). 여럿 고르기 |

정답 `answer.now` 는 **지금 일어나는 변화의 id 목록**(차례 무관). 틀리면 잘못 고른 보기에 ✕, 빠진 것이 있으면 어느 것인지는 밝히지 않고 △ 안내만 보인다.

보기에 쓸 수 있는 사실(리서치 11 6-1절, 공통국어2 139쪽 사례 확인 — 문장은 새로 쓴다):
- 지금의 변화(정답): 말머리 예사소리를 된소리로 내는 발음이 늘어남('작다' 표준 발음은 [작ː따]) · '혼밥' 같은 줄임 신어 · 사물 높임 '커피 나오셨습니다' · ㅔ/ㅐ 구별 약화(표준 발음법은 여전히 구별)
- 지난 변화(오답 보기): 근대 국어의 변화(리서치 05 근대 행) — ㅸ·ㅿ 소멸, 주격 조사 '가' 출현 등
- 쓰지 않는 것: 오타 유행어(스빈다·고나리자 — 교과서에만 있어 △), 설문 수치를 정답 근거로 삼는 것

## ③ 500년 뒤 예측 한 줄 (`config.predict`, 선택)

`predict: true` 면 글 칸이 보인다. **채점하지 않고, 답(`answer`)에 들어가지 않으며, 기록에도 남지 않는다**
(기믹 접점에 글을 저장할 통로가 없다 — 같은 창을 이 세션 안에서 다시 열면 남아 있다). 기록에 남겨야 하면 장면 끝 '돌아보기 한 줄'에서 다시 묻는다.

## 정답 (`answer`)

```js
{ order: { <낱말 id>: ['<낱말 id>.0', '<낱말 id>.1', …] }, now: [<지금의 변화 보기 id>, …] }
```
`now` 를 쓰지 않으면 `now` 키를 빼고, 기믹도 그 부분을 그리지 않는다.

## 도움 2단계 강조 (`hints[1]`)

낱말 id(`'jopssal'`), `'order'`(① 전체), `'now'`(② 전체), 또는 그 배열. 그 부분에 ★ 와 점선 테두리가 붙는다.

## 틀린 부분 표시

틀린 제출 바로 뒤 틀린 **나루**와 잘못 고른 **보기**에 ✕ 와 붉은 점선 테두리(색만으로 나누지 않음). 고치면 걷힌다.
3번째 틀림(또는 끝난 과제 다시 열기)에는 정답 차례가 ○ 와 함께 채워지고 고칠 수 없게 된다.

## 원문 카드 (`config.orig`, 선택)

블록 id 목록을 주면 기믹 위에 原文 카드를 보인다(종장 고등판에는 보통 쓰지 않음).

## 전체 예시 (장면 데이터 `items` 안, 고등판)

```js
{
  id: 's12.t1', kind: 'task', levels: ['h1', 'h23'], label: '변화의 강', gimmick: 'wordRiver',
  config: {
    words: [
      { id: 'anpak',    label: '안팎',   forms: ['안[ㅍㅏㅺ]', '안팎'] },
      { id: 'jopssal',  label: '좁쌀',   forms: ['조[ㅄㆍㄹ]', '좁[ㅄㆍㄹ]', '좁[ㅆㆍㄹ]', '좁쌀'] },
      { id: 'sukgarak', label: '숟가락', forms: ['술', '숫가락', '숟가락'] },
      { id: 'salkogi',  label: '살코기', forms: ['[ㅅㆍㄹ]고기', '살코기'] }
    ],
    now: {
      choices: [
        { id: 'n1', text: '(새로 쓴 문장: 말머리를 된소리로 내는 발음이 늘어남)' },
        { id: 'n2', text: '(새로 쓴 문장: 줄임 신어가 생겨 사전에 오름)' },
        { id: 'n3', text: '(새로 쓴 문장: ㅔ와 ㅐ를 소리로 구별하지 않는 사람이 많음)' },
        { id: 'n4', text: '(새로 쓴 문장: ㅸ과 ㅿ이 쓰이지 않게 됨 — 지난 변화)' }
      ]
    },
    predict: true
  },
  answer: {
    order: {
      anpak: ['anpak.0', 'anpak.1'],
      jopssal: ['jopssal.0', 'jopssal.1', 'jopssal.2', 'jopssal.3'],
      sukgarak: ['sukgarak.0', 'sukgarak.1', 'sukgarak.2'],
      salkogi: ['salkogi.0', 'salkogi.1']
    },
    now: ['n1', 'n2', 'n3']
  },
  hints: ['(1단계 힌트 — 장면 작성자가 새로 쓴다)', 'jopssal'],
  explain: '(풀이 — 장면 작성자가 새로 쓴다)'
}
```

- 옛한글 음절(`안파ᇧ`·`조ᄡᆞᆯ`…)을 장면 데이터에 새로 넣으면 글꼴 범위 점검(font-coverage)이 물결 끝 글꼴 재생성을 요구할 수 있다.
- spec §7 표 아래 규칙(조정값): 종장 고등판의 순서 놓기는 기믹 과제만으로 끝날 수 있다(해독 항목 없이).
