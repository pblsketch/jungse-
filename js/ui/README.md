# 화면 흐름 UI 메모 (README에 옮길 내용)

## 주소 값 (spec §19-1, §9)

| 키 | 값 | 하는 일 |
|---|---|---|
| `level` | `m`(중학교) · `h1`(고1) · `h23`(고2~3) | 이번 접속의 학교급. 기기에 기록이 있으면 **이번 접속에만** 쓰고 기록의 학교급은 바꾸지 않는다. 기록이 없는 첫 실행이면 처음 정하기의 학교급 단계를 건너뛰고 이 값을 처음 학교급으로 저장한다. 진행은 이 학교급 칸에 저장된다. |
| `teacher` | `1` | 이번 접속에서 교사 모드를 켠다. 저장하지 않으므로 이 값 없이 새로 고침하면 꺼진다. |

예: `index.html?level=h1` · 전자칠판 `index.html?teacher=1&level=h23`

- 모르는 값(`level=x`, `teacher=0` 등)은 없는 것으로 본다.
- 교사 모드를 `teacher=1`로 켜면 교사 모드를 끌 때까지 기기의 학생 기록을 **읽지도 쓰지도 않는다**. 학교급 값이 없으면 시작할 때 학교급을 고른다.
- 설정의 `교사 모드 켜기` 단추로도 켤 수 있다(잠금 없음). 주소에 학교급이 없으면 이때 학교급을 고른다.

## 저장되지 않는 것

교사 모드가 켜져 있다는 사실, 교사 모드 중의 설정·진행, 수첩 이미지의 이름·번호, 주소 학교급(첫 실행 제외).

## 화면 문구

모두 `js/data/text-ui.js`(`NM.data.TEXT.ui`)에 있다. 끼워 넣는 값은 `%이름%`으로 적는다.
